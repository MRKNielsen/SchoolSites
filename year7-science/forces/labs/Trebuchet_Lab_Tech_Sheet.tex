% ── Purpose ──────────────────────────────────────────────────────────────────
\sechead{What the students are doing}
Students launch a beanbag from a desktop trebuchet with \textbf{five different counterweights}, three launches each (\textbf{15 launches}, allow 50--60 minutes). They measure how far each launch goes ($R$) with a tape, and a \textbf{PASCO wireless sensor strapped to the trebuchet's arm} records how fast the arm swings. Students work from the \emph{Trebuchet Investigation} booklet.

% ── Setup + Safety side by side ───────────────────────────────────────────────
\begin{minipage}[t]{0.50\linewidth}
\sechead{Setup before lesson}
\begin{enumerate}[itemsep=1pt, leftmargin=1.5em, topsep=2pt]
  \item Clear an 8\,m floor strip per station, all launching one way.
  \item Tape a \textbf{``0\,m'' line} along the front edge of each base; lay the measuring tape from it down the range.
  \item Mark a \textbf{1\,m exclusion zone} around each trebuchet.
  \item Sort the slotted masses into five counterweights per station.
  \item Check sensor coin cells; pair each with its group's device.
\end{enumerate}
\end{minipage}
\hfill
\begin{minipage}[t]{0.46\linewidth}
\sechead{Safety}
\begin{itemize}[itemsep=1pt, leftmargin=1.5em, topsep=2pt, label=\textbullet]
  \item \textbf{Risk level: Medium.} Teacher supervises all launches.
  \item Safety glasses worn by all students during launching.
  \item Only one person operates each trebuchet; others stand \textbf{behind} it.
  \item Nobody in front of or beside the launch path.
  \item Beanbags only --- no ball bearings or golf balls.
  \item Projectiles retrieved only on teacher's ``all clear''.
  \item Masses changed only with the arm hanging at rest.
\end{itemize}
\end{minipage}

{\footnotesize\color{LineGrey}
\textbf{Key:}\;
$R$ = distance from the ``0\,m'' line (front of the base) to where the projectile first lands, measured each launch.\;
\textbf{Counterweights:} the lightest that throws reliably to the heaviest the frame takes safely, five evenly spaced.}
