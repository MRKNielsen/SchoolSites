Unit 1 Workbooks

How these work

Read this once, at the start of the unit.

One dataset, all eight workbooks
Victorian climate observations for 2025 — four regions, six weather stations, 2190 daily readings. The same data runs through database design, SQL, statistics and visualisation, so what you learn in week 2 is still useful in week 8.

Data dictionary
Every table, every column, its data type, its units and its allowed range. Keep it open while you work — half of data analysis is knowing what a column actually holds.

Instructions

The workbooks

Each one goes with the topic named on its card, and is the fourth lesson of that week. Download the file and open it in marimo.

W1
Exploring the dataset .py
Topics 2–3 · How big the data is, what one row holds, and why every value arrives as text. Four checked exercises.
W2
Finding the faults .py
Topic 4 · A raw extract with nine kinds of fault in it — missing values, units typed into numbers, duplicates, orphans, impossible readings. Eight checked exercises.
W3
Database design .py
Topics 10–11 · You build the database in DB Browser; the workbook inspects it. Three checks, each stricter than the last: tables, then keys and naming, then the relationships.
W4
SQL I — selecting and filtering .py
Topic 12 · SELECT, WHERE, ORDER BY, LIMIT and BETWEEN, against the real database. Five checked queries.
W5
SQL II — joins .py
Topic 13 · Putting the three tables back together, including what SQLite does when you forget the ON clause. Four checked queries.
W6
SQL III — aggregation .py
Topic 14 · COUNT, AVG, GROUP BY and HAVING — and which rows end up in each group. Five checked queries.
W7
Descriptive statistics .py
Topic 15 · Worked in the spreadsheet, checked here. Mean against median on skewed rainfall data, and standard deviation as coastal against inland. Six checked answers.
W8
Visualisation conventions .py
Topic 16 · The numbers a chart needs before you draw it, then the same bar chart drawn twice — once honestly, once with a truncated axis. Six checked answers.
