Key ideaAn equation is a balance ⚖. Do the same inverse operation to both sides, one step per line, until x is alone.

Key idea — one special rule

Solve like an equation…same inverse operations, both sides — the inequality sign stays put…
…exceptmultiplying or dividing by a negative flips the sign. Test it: 2 < 4, but ×(−1) gives −2 > −4. The flip keeps it true!

Worked example 4

Worked exampleSolve 3 − 2x ≥ 9 and show the solution on a number line.
1− 3 both sides: −2x ≥ 6
2÷ (−2) — FLIP the sign: x ≤ −3
3Number line: closed circle at −3 (it is included), arrow to the left.
4Check with x = −4: 3 − 2(−4) = 11 ≥ 9 ✔

Your turnSolve 2x + 1 < 7 and graph it on a number line.
Hint: no negatives here — the sign does not flip. Open or closed circle?
✔ 2x < 6 → x < 3 — open circle at 3 (3 is NOT included), arrow left.

🎯 Learning intentions — today I will…

Key idea — gradient formula, then one point

m = \(\dfrac{y_{2} - y_{1}}{x_{2} - x_{1}}\)
Routine1️⃣ m from the two points → 2️⃣ y = mx + c with ONE point substituted → find c → 3️⃣ check with the OTHER point.

Worked example 9

4Check with (3, 11): 4(3) − 1 = 11 ✔

Key ideaLine the equations up. If one variable has matching coefficients: same signs → subtract; opposite signs → add. That variable vanishes.

Worked example 17

Worked exampleSketch the region y > x − 2.
1Boundary: y = x − 2 — strict inequality (>) → dashed line.
2Test (0, 0): is 0 > 0 − 2? Yes → (0, 0)'s side is the region.
3Shade the side containing (0, 0) (above the line) and label the region.
