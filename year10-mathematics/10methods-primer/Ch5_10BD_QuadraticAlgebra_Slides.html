Factorising expressions

🎯 Learning intentions — today I will…

  • take out the highest common factor
  • factorise a difference of two squares

Key idea — expanding in reverse

Always firstTake out the HCF: 3x² − 12x = 3x(x − 4). Check by expanding back!
DOPS in reversea² − b² = (a + b)(a − b) — two squares with a MINUS between.
“First I look for a common factor, then I look for two squares.”

Worked example 2

Worked exampleFactorise: a) 3x² − 12x   b) x² − 25   c) 4x² − 36
1a) HCF is 3x: 3x(x − 4)
2b) DOPS: x² − 25 = (x + 5)(x − 5)
3c) HCF first: 4(x² − 9)
4Then DOPS: 4(x + 3)(x − 3) (two steps — many students stop too early!)

LESSON 3 — SECTION 5C

Multiplying and dividing algebraic fractions

🎯 Learning intentions — today I will…

  • cancel common FACTORS only
  • multiply and divide algebraic fractions
  • factorise before cancelling

Key idea — factorise, then cancel

The golden ruleOnly factors cancel — never terms. \(\dfrac{x + 3}{3}\) does NOT cancel; \(\dfrac{3(x + 2)}{3}\) = x + 2 does.
Routine1️⃣ Factorise every top and bottom → 2️⃣ cancel matching brackets → 3️⃣ multiply what is left. Dividing? Flip the second fraction first.

Worked example 3

Worked exampleSimplify: a) \(\dfrac{x^{2} - 9}{x + 3}\)   b) \(\dfrac{x - 1}{4} \times \dfrac{8}{3(x - 1)}\)
1a) Factorise the top: \(\dfrac{(x + 3)(x - 3)}{x + 3}\)
2Cancel the bracket: x − 3
3b) Cancel (x − 1) and 8 with 4: \(\dfrac{1}{1} \times \dfrac{2}{3}\)
4Answer: \(\dfrac{2}{3}\)

Your turn

Your turnSimplify: \(\dfrac{x^{2} - 4}{x + 2}\)   and   \(\dfrac{x + 1}{5} \div \dfrac{x + 1}{10}\)
Hint: dividing → flip the second fraction and multiply.
✔ x − 2   and   \(\dfrac{x + 1}{5} \times \dfrac{10}{x + 1}\) = 2
📘 Your work: Exercise 5C (start)
  • Simplify, multiply, then divide questions
  • Factorise BEFORE you cancel — every time
  • Cross out cancelled brackets in pencil so the marker can see

Key idea — multiply to c, add to b

The searchFor x² + bx + c, find two numbers that multiply to c and add to b. Then (x + □)(x + □).
Sign detectivec positive → same signs (both b's sign). c negative → different signs (bigger number takes b's sign).

LESSON 7 — SECTION 5E (10A)

Factorising non-monic quadratic trinomials

🎯 Learning intentions — today I will…

  • use the grouping (ac) method
  • split the middle term correctly
  • factorise ax² + bx + c with a ≠ 1

Key idea — the grouping method

For ax² + bx + c1️⃣ Find two numbers that multiply to a × c and add to b → 2️⃣ split the middle term → 3️⃣ factorise in pairs (grouping).
Why a × c?The a is tangled with the x² — multiplying a × c untangles the search.

Worked example 7

Worked exampleFactorise 2x² + 7x + 3
1a × c = 6, add to 7: the numbers are 6 and 1
2Split the middle: 2x² + 6x + x + 3
3Group in pairs: 2x(x + 3) + 1(x + 3)
4Common bracket: (x + 3)(2x + 1) — expand to check ✔

Your turn

Your turnFactorise 3x² + 8x + 4
Hint: a × c = 12, add to 8 → 6 and 2.
✔ 3x² + 6x + 2x + 4 = 3x(x + 2) + 2(x + 2) = (x + 2)(3x + 2)
📘 Your work: Exercise 5E (start)
  • Grouping method, positive coefficients first
  • Both bracket pairs must match at step 3 — if not, re-split
  • Say it: “multiply to a-c, add to b.”

LESSON 9 — SECTION 5F

Factorising by completing the square

🎯 Learning intentions — today I will…

  • complete the square on x² + bx + c
  • factorise using DOPS with surds
  • know when completing the square is needed

Key idea — build the perfect square

x² + bx = (x + \(\dfrac{b}{2}\))² − (\(\dfrac{b}{2}\))²
Then DOPS(x + 3)² − 7 = (x + 3 + \(\sqrt{7}\))(x + 3 − \(\sqrt{7}\)) — the “squares” can be surds! (Unit 2 skills return.)
When?When the magic numbers do not exist — e.g. x² + 6x + 2 has no whole-number pair.

Worked example 9

Worked exampleFactorise x² + 6x + 2 by completing the square.
1Halve 6 → 3: x² + 6x + 2 = (x + 3)² − 9 + 2
2Simplify: (x + 3)² − 7
3DOPS with \(\sqrt{7}\): (x + 3 + \(\sqrt{7}\))(x + 3 − \(\sqrt{7}\))

Your turn

Your turnFactorise x² − 4x − 1 by completing the square.
Hint: (x − 2)² − 4 − 1.
✔ (x − 2)² − 5 = (x − 2 + \(\sqrt{5}\))(x − 2 − \(\sqrt{5}\))

LESSON 10 — SECTION 5G

Solving quadratic equations by factorising

🎯 Learning intentions — today I will…

  • rearrange to standard form = 0
  • apply the null factor law
  • solve monic and non-monic quadratic equations

Key idea — the null factor law

Null factor lawIf A × B = 0, then A = 0 or B = 0. This ONLY works when one side is zero — rearrange first!
Routine1️⃣ Everything to one side (= 0) → 2️⃣ factorise fully → 3️⃣ each factor = 0 → 4️⃣ solve each little equation.

Worked example 10

Worked exampleSolve: a) x² − 3x − 10 = 0   b) 2x² = 8x
1a) Factorise: (x − 5)(x + 2) = 0
2Null factor law: x = 5 or x = −2
3b) Rearrange first: 2x² − 8x = 0 (never divide by x — you lose a solution!)
4Factorise: 2x(x − 4) = 0 → x = 0 or x = 4

Your turn

Your turnSolve x² + 2x − 24 = 0
Hint: multiply to −24, add to 2.
✔ (x + 6)(x − 4) = 0 → x = −6 or x = 4
📘 Your work: Exercise 5G
  • Standard form first, always — “= 0” before factorising
  • Two answers is normal for quadratics
  • Trap check: 2x² = 8x has TWO solutions, not one

LESSON 11 — SECTION 5H

Applications of quadratic equations

🎯 Learning intentions — today I will…

  • form a quadratic equation from a real situation
  • solve it and REJECT impossible answers
  • answer in words with units

Key idea — the five-step routine

Applications routine1️⃣ Define the variable with units → 2️⃣ Form the equation → 3️⃣ Solve (factorise + NFL) → 4️⃣ Reject impossible solutions (negative lengths!) → 5️⃣ Answer in words.
“x = ___ is rejected because a length cannot be negative.”

Worked example 11

Worked exampleA rectangle is 5 m longer than it is wide. Its area is 84 m². Find its dimensions.
1Define: let x = width (m); length = x + 5.
2Form: x(x + 5) = 84 → x² + 5x − 84 = 0
3Solve: (x + 12)(x − 7) = 0 → x = −12 or x = 7
4Reject: x = −12 (width cannot be negative).
5Answer: “The rectangle is 7 m wide and 12 m long.” Check: 7 × 12 = 84 ✔

Your turn

Your turnThe product of two consecutive whole numbers is 72. Find the numbers.
Hint: n(n + 1) = 72 → n² + n − 72 = 0.
✔ (n + 9)(n − 8) = 0 → n = 8 (reject −9 if the question wants positive numbers) → 8 and 9
📘 Your work: Exercise 5H
  • Area, number and “consecutive” problems — draw a diagram for every shape
  • The reject line earns a mark: write it
  • Answers in words with units, always

Solving quadratic equations by completing the square

🎯 Learning intentions — today I will…

  • give exact surd answers with ±

Key idea — isolate the square, ± root

Routine1️⃣ Complete the square → 2️⃣ isolate: (x + h)² = k → 3️⃣ ± square root → 4️⃣ solve both.
Remember ±(x + 2)² = 7 has TWO solutions: x + 2 = \(\sqrt{7}\) and x + 2 = −\(\sqrt{7}\).

Worked example 12

Worked exampleSolve x² + 4x − 3 = 0, giving exact answers.
1Complete the square: (x + 2)² − 4 − 3 = 0
2Isolate: (x + 2)² = 7
3± root: x + 2 = ±\(\sqrt{7}\)
4Answer: x = −2 + \(\sqrt{7}\) or x = −2 − \(\sqrt{7}\)

LESSON 13 — SECTION 5J

Solving using the quadratic formula

🎯 Learning intentions — today I will…

  • identify a, b and c from standard form
  • substitute carefully into the formula
  • use Δ to predict the number of solutions

Key idea — the formula that always works

x = \(\dfrac{- b \pm \sqrt{b^{2} - 4ac}}{2a}\)
The discriminantΔ = b² − 4ac:   Δ > 0 → two solutions · Δ = 0 → one · Δ < 0 → none.
Substitution disciplineWrite a = …, b = …, c = … first. Brackets around negatives: b = −3 → −b = 3, b² = 9.

Worked example 13

Worked exampleSolve 2x² + 3x − 4 = 0, exact and to 2 d.p.
1a = 2, b = 3, c = −4. Δ = 9 − 4(2)(−4) = 9 + 32 = 41 > 0 → two solutions.
2Formula: x = \(\dfrac{- 3 \pm \sqrt{41}}{4}\) (exact)
3Decimals: x ≈ 0.85 or x ≈ −2.35

Your turn

Your turnSolve x² − 5x + 2 = 0 exactly.
Hint: Δ = 25 − 8 = 17.
✔ x = \(\dfrac{5 \pm \sqrt{17}}{2}\)
📘 Your work: Exercise 5J (start)
  • Δ first, then the formula
  • a, b, c line before every substitution
  • Exact AND decimal answers when asked — read the command words

Worked example 17

Worked exampleDivide x³ − 2x² − 5x + 6 by (x − 1).
1x³ ÷ x = x²: write x²; multiply back x²(x − 1) = x³ − x²; subtract → −x² − 5x

4Answer: quotient x² − x − 6, remainder 0 — so x³ − 2x² − 5x + 6 = (x − 1)(x² − x − 6) = (x − 1)(x − 3)(x + 2)!
