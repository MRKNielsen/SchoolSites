Key idea

Almost every inequality proof at this level is the same move: bring everything to one side and show the result is a square, a sum of squares, or otherwise visibly non-negative.

Lesson 1 · 2C

The difference method

  • To prove LHS \(\geq\) RHS: show LHS − RHS \(\geq 0\), usually via squares.
  • AM–GM falls out of \((a-b)^2 \geq 0\).
  • Track equality conditions.

The difference method — worked examples

Example 1A

Prove that \(a^2 + b^2 \geq 2ab\) for all real \(a, b\), and hence derive the AM–GM inequality \(\dfrac{x+y}{2} \geq \sqrt{xy}\) for \(x, y \geq 0\).

  1. 1 Difference: \(a^2 + b^2 - 2ab = (a - b)^2 \geq 0\), with equality iff \(a = b\).
  2. 2 Now put \(a = \sqrt{x}\), \(b = \sqrt{y}\) (legal since \(x, y \geq 0\)): \(x + y \geq 2\sqrt{xy}\).
  3. ✓ Divide by 2: \(\dfrac{x+y}{2} \geq \sqrt{xy}\), equality iff \(x = y\). ∎
Direction of writing

Scratch work may run backwards from the target; the written proof must run forwards from known facts. Assuming the conclusion scores poorly.

Example 1B

Prove that \(\dfrac{a}{b} + \dfrac{b}{a} \geq 2\) for all \(a, b > 0\), and state when equality holds.

  1. 1 Difference over a common denominator: \(\dfrac{a}{b} + \dfrac{b}{a} - 2 = \dfrac{a^2 + b^2 - 2ab}{ab}\).
  2. 2 The numerator is \((a-b)^2 \geq 0\); the denominator \(ab > 0\) because both \(a\) and \(b\) are positive.
  3. 3 A non-negative number over a positive number is non-negative, so the difference is \(\geq 0\).
  4. ✓ Hence \(\dfrac{a}{b} + \dfrac{b}{a} \geq 2\), with equality iff \((a-b)^2 = 0\), i.e. \(a = b\). ∎
Where the hypothesis went

\(a, b > 0\) was used once, on the sign of \(ab\) — and it is essential. At \(a = 1, b = -1\) the expression equals \(-2\).

Example 1C

Prove that \(a^2 + b^2 + 1 \geq ab + a + b\) for all real \(a, b\).

  1. 1 The difference \(a^2 + b^2 + 1 - ab - a - b\) is not a single square. Double it — the standard move when cross terms appear.
  2. 2 \(2(a^2 + b^2 + 1) - 2(ab + a + b) = 2a^2 + 2b^2 + 2 - 2ab - 2a - 2b\).
  3. 3 Regroup into three squares: \(= (a - b)^2 + (a - 1)^2 + (b - 1)^2\). Expanding confirms the identity.
  4. ✓ A sum of squares is \(\geq 0\), so twice the difference is \(\geq 0\), so the difference is. Equality needs all three squares zero: \(a = b = 1\). ∎
Why doubling works

Each cross term \(-2ab\) needs an \(a^2\) and a \(b^2\) to pair with. With three cross terms and only one copy of each square to go round, doubling supplies the missing halves. Same trick as Checkpoint 1's \(a^2+b^2+c^2 \geq ab+bc+ca\).

Example 1D

Prove that \((a+b)(b+c)(c+a) \geq 8abc\) for all \(a, b, c > 0\).

  1. 1 Expanding is a trap — 8 terms and no obvious grouping. Instead apply Example 1A to each bracket separately.
  2. 2 AM–GM gives \(a + b \geq 2\sqrt{ab}\), \(\;b + c \geq 2\sqrt{bc}\), \(\;c + a \geq 2\sqrt{ca}\). All six quantities are positive.
  3. 3 Multiplying inequalities is legitimate because every side is positive: \((a+b)(b+c)(c+a) \geq 8\sqrt{ab}\sqrt{bc}\sqrt{ca}\).
  4. ✓ And \(\sqrt{ab}\sqrt{bc}\sqrt{ca} = \sqrt{a^2b^2c^2} = abc\). So the product is \(\geq 8abc\), with equality iff \(a = b = c\). ∎
The condition that matters

You may only multiply inequalities together when all the terms are positive. \(-3 > -5\) and \(-3 > -5\), but \(9 < 25\). State the positivity — it is a mark.

Example 1E

Prove that \(\dfrac{1}{x} + \dfrac{1}{y} \geq \dfrac{4}{x+y}\) for all \(x, y > 0\).

  1. 1 Combine the left side: \(\dfrac{1}{x} + \dfrac{1}{y} = \dfrac{x+y}{xy}\).
  2. 2 Difference: \(\dfrac{x+y}{xy} - \dfrac{4}{x+y} = \dfrac{(x+y)^2 - 4xy}{xy(x+y)}\).
  3. 3 The numerator is \(x^2 + 2xy + y^2 - 4xy = (x - y)^2 \geq 0\); the denominator \(xy(x+y) > 0\) since \(x, y > 0\).
  4. ✓ So the difference is \(\geq 0\), giving the result, with equality iff \(x = y\). ∎
Worth recognising

Rearranged, this says \(\dfrac{x+y}{2} \geq \dfrac{2}{\frac1x + \frac1y}\) — the arithmetic mean is at least the harmonic mean. With Example 1A giving AM \(\geq\) GM, you have now proved that the arithmetic mean dominates both of the other classical means. (The remaining link, GM \(\geq\) HM, follows by applying Example 1A to \(\tfrac1x\) and \(\tfrac1y\) — worth trying.)

Checkpoint 1 — your turn

Try it! (≈6 min)
  • (a) Prove that \(a^2 + b^2 + c^2 \geq ab + bc + ca\) for all real \(a, b, c\). Hint: multiply the difference by 2.
  • (b) When does equality hold?
  • (a) \(2(a^2+b^2+c^2) - 2(ab+bc+ca) = (a-b)^2 + (b-c)^2 + (c-a)^2 \geq 0\). ∎
  • (b) Equality iff every square vanishes: \(a = b = c\).
  • Sum-of-squares is the workhorse: if the difference isn't one square, try to write it as several.
Lesson 2 · 2C

Fractions and surds

  • \(x + \tfrac{1}{x} \geq 2\): the fraction version of the difference method.
  • Conjugates turn surd differences into single fractions you can bound.
  • Check that every hypothesis earns its keep.

Fractions and surds — worked examples

Example 2A

Prove that \(x + \dfrac{1}{x} \geq 2\) for all \(x > 0\), with equality only at \(x = 1\).

  1. 1 Difference: \(x + \dfrac{1}{x} - 2 = \dfrac{x^2 - 2x + 1}{x} = \dfrac{(x-1)^2}{x}\).
  2. 2 For \(x > 0\): numerator \(\geq 0\), denominator \(> 0\), so the difference is \(\geq 0\).
  3. ✓ Equality iff \((x-1)^2 = 0\), i.e. \(x = 1\). ∎
Hypotheses earn their keep

Where did \(x > 0\) get used? The denominator's sign. If a given condition never appears in your proof, suspect the proof.

Example 2B

Prove that \(\sqrt{n+1} - \sqrt{n} < \dfrac{1}{2\sqrt{n}}\) for all integers \(n \geq 1\).

  1. 1 Rationalise: \(\sqrt{n+1} - \sqrt{n} = \dfrac{(\sqrt{n+1} - \sqrt{n})(\sqrt{n+1} + \sqrt{n})}{\sqrt{n+1} + \sqrt{n}} = \dfrac{1}{\sqrt{n+1} + \sqrt{n}}\).
  2. 2 Since \(\sqrt{n+1} > \sqrt{n}\), the denominator satisfies \(\sqrt{n+1} + \sqrt{n} > 2\sqrt{n}\).
  3. ✓ Bigger denominator, smaller fraction: \(\dfrac{1}{\sqrt{n+1} + \sqrt{n}} < \dfrac{1}{2\sqrt{n}}\). ∎
Tool worth naming

Multiplying by the conjugate turns a difference of surds into a single fraction you can bound. This trick reappears in exam proofs constantly.

Example 2C

Prove that \((a + b)\left(\dfrac{1}{a} + \dfrac{1}{b}\right) \geq 4\) for all \(a, b > 0\).

  1. 1 Expand first — the structure only becomes visible afterwards.
  2. 2 \((a+b)\left(\dfrac{1}{a} + \dfrac{1}{b}\right) = 1 + \dfrac{a}{b} + \dfrac{b}{a} + 1 = 2 + \dfrac{a}{b} + \dfrac{b}{a}\).
  3. 3 By Example 1B, \(\dfrac{a}{b} + \dfrac{b}{a} \geq 2\) for positive \(a, b\).
  4. ✓ So the expression is \(\geq 2 + 2 = 4\), with equality iff \(a = b\). ∎
Same fact, third disguise

This is Example 1E rearranged, and Example 1B in a wrapper. Recognising that three exam questions are one theorem is worth more than three memorised proofs.

Example 2D

Prove that \(\sqrt{a} + \sqrt{b} > \sqrt{a + b}\) for all \(a, b > 0\).

  1. 1 Both sides are positive, so squaring is reversible and comparing squares settles it.
  2. 2 \(\left(\sqrt{a} + \sqrt{b}\right)^2 = a + 2\sqrt{ab} + b\), and \(\left(\sqrt{a+b}\right)^2 = a + b\).
  3. 3 Difference of squares: \(\left(a + 2\sqrt{ab} + b\right) - (a+b) = 2\sqrt{ab} > 0\), since \(a, b > 0\).
  4. ✓ The left square exceeds the right square, and both bases are positive, so \(\sqrt{a} + \sqrt{b} > \sqrt{a+b}\). ∎
Say why squaring is safe

\(u^2 > v^2\) implies \(u > v\) only when \(u, v \geq 0\) — otherwise \((-3)^2 > 2^2\) would give \(-3 > 2\). One sentence establishing positivity turns a suspect step into a sound one.

Example 2E

Prove that \(\sqrt{a} - \sqrt{b} < \sqrt{a - b}\) for all reals \(a > b > 0\).

  1. 1 Both sides are positive: \(a > b\) gives \(\sqrt a > \sqrt b\) on the left and \(a - b > 0\) on the right. So compare squares.
  2. 2 \(\left(\sqrt{a} - \sqrt{b}\right)^2 = a - 2\sqrt{ab} + b\) and \(\left(\sqrt{a-b}\right)^2 = a - b\).
  3. 3 Their difference: \((a - b) - \left(a - 2\sqrt{ab} + b\right) = 2\sqrt{ab} - 2b = 2\sqrt{b}\left(\sqrt{a} - \sqrt{b}\right)\).
  4. ✓ That is positive, since \(b > 0\) and \(\sqrt a > \sqrt b\). So the right square is larger, and with both bases positive the inequality follows. ∎
Read it as a fact about roots

The square-root function grows ever more slowly, so a gap of \(a - b\) high up the curve produces a smaller rise than the same gap starting at 0. This is the same phenomenon Example 2B measured precisely.

Checkpoint 2 — your turn

Try it! (≈5 min)

Prove the companion bound: \(\sqrt{n+1} - \sqrt{n} > \dfrac{1}{2\sqrt{n+1}}\) for all integers \(n \geq 1\).

  • Same conjugate step: \(\sqrt{n+1} - \sqrt{n} = \dfrac{1}{\sqrt{n+1} + \sqrt{n}}\).
  • This time bound the other way: \(\sqrt{n+1} + \sqrt{n} < 2\sqrt{n+1}\), so the fraction exceeds \(\dfrac{1}{2\sqrt{n+1}}\). ∎
  • Together the two bounds sandwich \(\sqrt{n+1}-\sqrt{n}\) — the pair is a favourite exam question.
Lesson 3 · 2D

Telescoping series

  • Split the general term as \(f(k) - f(k+1)\); the interior cancels.
  • Products telescope too — match numerators with denominators.
  • Limits fall out of the surviving boundary terms.

Telescoping sums — worked examples

Example 4A

Evaluate \(\displaystyle\sum_{k=1}^{n} \frac{1}{k(k+1)}\), and its limit as \(n \to \infty\).

  1. 1 Partial fractions: \(\dfrac{1}{k(k+1)} = \dfrac{1}{k} - \dfrac{1}{k+1}\).
  2. 2 Write out a few terms: \(\left(1 - \tfrac12\right) + \left(\tfrac12 - \tfrac13\right) + \cdots + \left(\tfrac1n - \tfrac{1}{n+1}\right)\) — the interior cancels in pairs.
  3. ✓ Survivors: \(1 - \dfrac{1}{n+1} = \dfrac{n}{n+1} \to 1\) as \(n \to \infty\). ∎
Recognising a telescope

If the general term splits as \(f(k) - f(k+1)\) (or \(f(k+1) - f(k)\)), the sum collapses to boundary terms. Partial fractions is the usual splitter.

Example 4B

Evaluate \(\displaystyle\sum_{k=1}^{n} \frac{1}{(2k-1)(2k+1)}\), and its limit as \(n \to \infty\).

  1. 1 Partial fractions: \(\dfrac{1}{(2k-1)(2k+1)} = \dfrac{1}{2}\left(\dfrac{1}{2k-1} - \dfrac{1}{2k+1}\right)\). Keep the \(\tfrac12\) outside the sum.
  2. 2 The bracket at \(k\) ends on \(\dfrac{1}{2k+1}\) and the bracket at \(k+1\) starts on \(\dfrac{1}{2k+1}\) — consecutive brackets still cancel, even though the denominators skip the evens.
  3. 3 Survivors: \(\dfrac12\left(\dfrac11 - \dfrac{1}{2n+1}\right)\).
  4. ✓ \(= \dfrac{1}{2} \cdot \dfrac{2n}{2n+1} = \dfrac{n}{2n+1} \to \dfrac12\). Check \(n = 1\): \(\tfrac13\) from both. ✓ ∎
Always test at n = 1

Substituting \(n = 1\) into your closed form and comparing with the first term catches nearly every algebra slip, and it costs one line.

Example 4C

Prove that \(\displaystyle\sum_{k=1}^{n} k \cdot k! = (n+1)! - 1\).

  1. 1 Find the split. Partial fractions is useless here; instead notice \((k+1)! = (k+1)\cdot k! = k \cdot k! + k!\).
  2. 2 Rearranged, that gives exactly the term: \(k \cdot k! = (k+1)! - k!\) — of the form \(f(k+1) - f(k)\) with \(f(k) = k!\).
  3. 3 Sum: \((2! - 1!) + (3! - 2!) + \cdots + \big((n+1)! - n!\big)\) — the interior cancels.
  4. ✓ Survivors: \((n+1)! - 1! = (n+1)! - 1\). Check \(n = 3\): \(1 + 4 + 18 = 23 = 4! - 1\). ✓ ∎
Telescoping is bigger than partial fractions

The technique needs only that the term be a difference of consecutive values of some function. Fractions are the common case, not the definition — factorials, logs and surds telescope just as happily.

Example 4D

Evaluate \(\displaystyle\sum_{k=1}^{n} \ln\!\left(1 + \frac{1}{k}\right)\). Does it converge as \(n \to \infty\)?

  1. 1 Write the argument as a single fraction: \(1 + \dfrac1k = \dfrac{k+1}{k}\).
  2. 2 The log law splits it: \(\ln\dfrac{k+1}{k} = \ln(k+1) - \ln k\) — a difference of consecutive values of \(f(k) = \ln k\).
  3. 3 Sum: \((\ln 2 - \ln 1) + (\ln 3 - \ln 2) + \cdots + \big(\ln(n+1) - \ln n\big) = \ln(n+1) - \ln 1 = \ln(n+1)\).
  4. ✓ So the sum is \(\ln(n+1)\), which \(\to \infty\). The series diverges, even though its terms shrink to 0. ∎
A warning worth keeping

Terms tending to zero does not guarantee a series converges — this one is a clean counterexample you can prove in four lines. Telescoping gives you the exact partial sum, which is far stronger evidence than watching the terms shrink.

Seeing it: the interior cancels

Every middle term appears once with \(+\) and once with \(-\). Only the first and last survive.

Telescoping products — worked examples

Example 5A

Evaluate \(\displaystyle\prod_{k=2}^{n} \left(1 - \frac{1}{k^2}\right)\), and its limit as \(n \to \infty\).

  1. 1 Factor: \(1 - \dfrac{1}{k^2} = \dfrac{k^2-1}{k^2} = \dfrac{(k-1)(k+1)}{k^2}\), so each numerator meets a matching denominator along the product.
  2. 2 Separate the two families: \(\displaystyle\prod_{k=2}^{n}\dfrac{k-1}{k} \cdot \prod_{k=2}^{n}\dfrac{k+1}{k} = \dfrac{1}{n} \cdot \dfrac{n+1}{2}\).
  3. ✓ Survivors: \(\dfrac{n+1}{2n} \to \tfrac12\) as \(n \to \infty\). Check \(n = 2\): \(1 - \tfrac14 = \tfrac34\) and \(\tfrac{3}{4}\). ✓ ∎
Same principle

Sums cancel by subtraction; products cancel by division. Either way, only the boundary survives.

Example 5B

Evaluate \(\displaystyle\prod_{k=1}^{n} \left(1 + \frac{1}{k}\right)\).

  1. 1 Each factor is \(1 + \dfrac1k = \dfrac{k+1}{k}\).
  2. 2 Write the product out: \(\dfrac{2}{1} \cdot \dfrac{3}{2} \cdot \dfrac{4}{3} \cdots \dfrac{n+1}{n}\) — every numerator cancels the next denominator.
  3. ✓ Survivors: \(\dfrac{n+1}{1} = n+1\). This grows without bound, so unlike Example 5A the product diverges. ∎
Compare with 4D

Taking logs turns this product into the sum of Example 4D: \(\ln\big(\prod(1+\tfrac1k)\big) = \sum \ln(1+\tfrac1k) = \ln(n+1)\). The same telescope, seen through a logarithm.

Example 5C

Evaluate \(\displaystyle\prod_{k=2}^{n} \left(1 - \frac{1}{k}\right)\).

  1. 1 Each factor is \(1 - \dfrac1k = \dfrac{k-1}{k}\).
  2. 2 Write it out: \(\dfrac{1}{2} \cdot \dfrac{2}{3} \cdot \dfrac{3}{4} \cdots \dfrac{n-1}{n}\) — this time each denominator cancels the next numerator.
  3. ✓ Survivors: \(\dfrac{1}{n} \to 0\). Check \(n = 3\): \(\tfrac12 \cdot \tfrac23 = \tfrac13\). ✓ ∎
Two tools, one truth

Telescoping finds this formula. Next week you will prove the same result by induction (T3W10, Example 3A) — worth comparing the two write-ups side by side, because they answer different questions: "what is it?" and "why is it always that?".

Checkpoint 3 — your turn

Try it! (≈6 min)

Evaluate \(\displaystyle\sum_{k=1}^{n} \frac{1}{k(k+2)}\). Careful: two boundary terms survive at each end.

  • \(\dfrac{1}{k(k+2)} = \dfrac12\left(\dfrac{1}{k} - \dfrac{1}{k+2}\right)\) — the gap of 2 means cancellation skips a term.
  • Survivors: \(\dfrac12\left(1 + \dfrac12 - \dfrac{1}{n+1} - \dfrac{1}{n+2}\right) = \dfrac34 - \dfrac{2n+3}{2(n+1)(n+2)}\).
  • Limit: \(\dfrac34\). Check \(n=1\): formula gives \(\tfrac34 - \tfrac{5}{12} = \tfrac13\) = \(\tfrac{1}{1\cdot3}\). ✓
Lesson 4 · Workshop

Proof-writing workshop

  • The frame, the flow, the finish: setting out arguments for full marks.
  • Diagnose a flawed proof.

Workshop: setting out a proof

  • Declare the frame: "Let \(n \geq 1\) be an integer" / "Suppose, for contradiction, that…".
  • One claim per line, each justified: algebra, a known inequality, or a previously proven line.
  • Direction forwards: known → target. Never begin with the statement to be proved.
  • Close it: state what was shown, note equality conditions if asked, and end with ∎ or "as required".
Marker's-eye view

Assessors award marks for visible logical structure. Two correct proofs can score differently if one hides its reasoning — make every inference inspectable.

Checkpoint 4 — find the flaw

Try it! (≈5 min)

A student "proves" \(a^2 + b^2 \geq 2ab\) like this:

"\(a^2 + b^2 \geq 2ab\). Subtract \(2ab\): \(a^2 - 2ab + b^2 \geq 0\). So \((a-b)^2 \geq 0\), which is true. Hence proved."

The algebra is right and the final line is true. What's wrong — and how should it be written?

  • The argument assumes the conclusion in line 1 and deduces something true — but true conclusions can follow from false premises, so nothing is proved.
  • The steps here are reversible, so the fix is to run them forwards: start from \((a-b)^2 \geq 0\), expand, add \(2ab\). Same algebra, valid direction.
  • Exam habit: scratch backwards, write forwards — and re-read your first line asking "is this known, or is it the target?"

Chapter 2C–D summary

  • Inequalities: difference \(\geq 0\), squares are your witnesses; AM–GM from \((a-b)^2 \geq 0\).
  • Surd bounds: multiply by the conjugate, then bound the denominator.
  • Telescoping: split into \(f(k) - f(k+1)\), keep only the boundary.
  • Written proofs run forwards, one justified claim per line.
