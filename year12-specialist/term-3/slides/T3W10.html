Key idea

Dominoes: prove the first one falls (base case), and that each falling domino knocks over the next (inductive step). Then they all fall.

Lesson 1 · 2E

The principle of mathematical induction

  • Base case + inductive step = infinitely many statements proved.
  • The framework, written in full, every time.
  • What induction is for — and where the base case starts.

The template

Principle

To prove \(P(n)\) for all integers \(n \geq n_0\):   (1) Base case: verify \(P(n_0)\).   (2) Inductive step: assume \(P(k)\) for some \(k \geq n_0\), and deduce \(P(k+1)\).

  • The assumption in step 2 is the inductive hypothesis — you must visibly use it.
  • Write the framework every time: base case, hypothesis, step, conclusion "by induction, \(P(n)\) holds for all \(n \geq n_0\)".
What induction is for

Claims indexed by integers: sum/product formulas, divisibility facts, inequalities like \(2^n > n^2\) for \(n \geq 5\).

Seeing it: dominoes

Base case: \(P(1)\) falls. Inductive step: each \(P(k)\) knocks over \(P(k+1)\). Conclusion: they all fall.

Checkpoint 1 — your turn

Try it! (≈4 min)
  • (a) For the claim "\(2^n > n^2\) for all \(n \geq 5\)", what exactly must the base case verify?
  • (b) A student proves the inductive step perfectly but skips the base case. What can go wrong? Find a claim where the step works but the claim is false.
  • (a) \(n = 5\): \(2^5 = 32 > 25 = 5^2\). ✓ (Not \(n = 1\) — the claim starts at 5, and indeed fails at \(n = 2, 3, 4\).)
  • (b) Example: "\(n = n + 1\) for all \(n\)". If \(k = k+1\) then adding 1 gives \(k+1 = k+2\) — a flawless step! But no domino ever falls: there's no base case.
Lesson 2 · 2E

Induction on sums

  • The move: add the \((m+1)\)-th term into the hypothesis, then massage.
  • Factor early — aim the algebra at the target formula.

Induction on sums — worked examples

Example 1A

Prove \(\displaystyle\sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}\) for all \(n \geq 1\).

  1. 1 Base: \(n=1\): LHS \(= 1\), RHS \(= \dfrac{1 \cdot 2 \cdot 3}{6} = 1\). ✓
  2. 2 Hypothesis: assume \(\displaystyle\sum_{k=1}^{m} k^2 = \frac{m(m+1)(2m+1)}{6}\) for some \(m \geq 1\).
  3. 3 Step: \(\displaystyle\sum_{k=1}^{m+1} k^2 = \frac{m(m+1)(2m+1)}{6} + (m+1)^2 = \frac{(m+1)\big(m(2m+1) + 6(m+1)\big)}{6}\) — factor \((m+1)\) out early.
  4. ✓ \(m(2m+1) + 6(m+1) = 2m^2+7m+6 = (m+2)(2m+3)\) — exactly the formula with \(n = m+1\). Conclude by induction. ∎
Example 1B

Prove \(\displaystyle\sum_{k=1}^{n} (2k - 1) = n^2\) for all \(n \geq 1\) — the sum of the first \(n\) odd numbers.

  1. 1 Base: \(n = 1\): LHS \(= 1\), RHS \(= 1^2 = 1\). ✓
  2. 2 Hypothesis: assume \(\displaystyle\sum_{k=1}^{m} (2k-1) = m^2\) for some \(m \geq 1\).
  3. 3 Step: the \((m+1)\)-th term is \(2(m+1) - 1 = 2m + 1\), so \(\displaystyle\sum_{k=1}^{m+1}(2k-1) = m^2 + 2m + 1\).
  4. ✓ \(m^2 + 2m + 1 = (m+1)^2\) — the formula at \(n = m+1\). By induction it holds for all \(n \geq 1\). ∎
Get the next term right

The commonest slip in a sum induction is adding the wrong thing. The \((m+1)\)-th term is the general term with \(k\) replaced by \(m+1\) — write that substitution down rather than guessing the pattern.

Example 1C

Prove \(\displaystyle\sum_{k=1}^{n} k^3 = \left[\frac{n(n+1)}{2}\right]^2\) for all \(n \geq 1\).

  1. 1 Base: \(n = 1\): LHS \(= 1\), RHS \(= \left[\tfrac{1\cdot2}{2}\right]^2 = 1\). ✓
  2. 2 Hypothesis: \(\displaystyle\sum_{k=1}^{m} k^3 = \dfrac{m^2(m+1)^2}{4}\) for some \(m \geq 1\).
  3. 3 Step: \(\displaystyle\sum_{k=1}^{m+1} k^3 = \dfrac{m^2(m+1)^2}{4} + (m+1)^3 = \dfrac{(m+1)^2\big(m^2 + 4(m+1)\big)}{4}\) — take out \((m+1)^2\).
  4. ✓ \(m^2 + 4m + 4 = (m+2)^2\), so the sum is \(\dfrac{(m+1)^2(m+2)^2}{4} = \left[\dfrac{(m+1)(m+2)}{2}\right]^2\) — the formula at \(n = m+1\). ∎
Factor before you expand

Multiplying everything out gives a quartic and a much harder factorisation. Pulling \((m+1)^2\) out first leaves a quadratic that factorises on sight. In every sum induction, take out the largest common factor before touching the brackets.

Example 1D

Prove \(\displaystyle\sum_{k=1}^{n} (3k - 2) = \frac{n(3n-1)}{2}\) for all \(n \geq 1\).

  1. 1 Base: \(n = 1\): LHS \(= 1\), RHS \(= \dfrac{1 \cdot 2}{2} = 1\). ✓
  2. 2 Hypothesis: \(\displaystyle\sum_{k=1}^{m}(3k-2) = \dfrac{m(3m-1)}{2}\) for some \(m \geq 1\).
  3. 3 Step: next term is \(3(m+1) - 2 = 3m+1\), so the new sum is \(\dfrac{m(3m-1)}{2} + (3m+1) = \dfrac{3m^2 - m + 6m + 2}{2} = \dfrac{3m^2 + 5m + 2}{2}\).
  4. ✓ \(3m^2 + 5m + 2 = (m+1)(3m+2)\), and \(3m + 2 = 3(m+1) - 1\). So the sum is \(\dfrac{(m+1)\big(3(m+1)-1\big)}{2}\) — the formula at \(n = m+1\). ∎
Aim at the target

Do not stop at \(\tfrac{(m+1)(3m+2)}{2}\) and hope the marker sees it. Rewrite \(3m+2\) as \(3(m+1)-1\) so the expression is visibly the formula with \(n\) replaced by \(m+1\). That last cosmetic line is where the mark is.

Example 1E

Prove \(\displaystyle\sum_{k=1}^{n} \frac{1}{k(k+1)} = \frac{n}{n+1}\) for all \(n \geq 1\).

  1. 1 Base: \(n = 1\): LHS \(= \dfrac{1}{1 \cdot 2} = \tfrac12\), RHS \(= \tfrac12\). ✓
  2. 2 Hypothesis: \(\displaystyle\sum_{k=1}^{m}\dfrac{1}{k(k+1)} = \dfrac{m}{m+1}\) for some \(m \geq 1\).
  3. 3 Step: add the next term: \(\dfrac{m}{m+1} + \dfrac{1}{(m+1)(m+2)} = \dfrac{m(m+2) + 1}{(m+1)(m+2)}\).
  4. ✓ \(m(m+2) + 1 = m^2 + 2m + 1 = (m+1)^2\), so the sum is \(\dfrac{(m+1)^2}{(m+1)(m+2)} = \dfrac{m+1}{m+2}\) — the formula at \(n = m+1\). ∎
Two proofs of one fact

Last week's telescoping argument (T3W09, Example 4A) discovered \(\tfrac{n}{n+1}\) without knowing it in advance; induction can only confirm a formula you already have. If a question hands you the answer, induction is usually the intended route.

Checkpoint 2 — your turn

Try it! (≈6 min)

Prove by induction: \(\displaystyle\sum_{k=1}^{n} k = \frac{n(n+1)}{2}\) for all \(n \geq 1\). Write all four framework lines.

  • Base: \(n=1\): LHS \(= 1 =\) RHS \(= \tfrac{1\cdot2}{2}\). ✓   Hypothesis: \(\sum_{k=1}^{m} k = \tfrac{m(m+1)}{2}\).
  • Step: \(\displaystyle\sum_{k=1}^{m+1} k = \frac{m(m+1)}{2} + (m+1) = \frac{(m+1)(m+2)}{2}\) — the formula at \(n = m+1\).
  • Conclusion: by the principle of mathematical induction, the formula holds for all \(n \geq 1\). ∎
Lesson 3 · 2E

Induction on divisibility

  • The pivot: solve the hypothesis for the power, substitute, factor.
  • Every divisibility induction runs on the same rails.

Induction on divisibility — worked examples

Example 2A

Prove that \(11^n - 6\) is divisible by 5 for all integers \(n \geq 1\).

  1. 1 Base: \(n = 1\): \(11 - 6 = 5\). ✓
  2. 2 Hypothesis: \(11^m - 6 = 5j\) for some integer \(j\) — solve for the power: \(11^m = 5j + 6\).
  3. ✓ Step: \(11^{m+1} - 6 = 11 \cdot 11^m - 6 = 11(5j + 6) - 6 = 55j + 60 = 5(11j + 12)\) — divisible by 5. ∎
The move

Divisibility inductions all pivot the same way: solve the hypothesis for the power, substitute, and factor the base out of what remains.

Example 2B

Prove that \(3^{2n} - 1\) is divisible by 8 for all integers \(n \geq 1\).

  1. 1 Read the exponent. \(3^{2n} = (3^2)^n = 9^n\), so the claim is that \(9^n - 1\) is divisible by 8. Rewriting first makes the step routine.
  2. 2 Base: \(n = 1\): \(9 - 1 = 8\). ✓
  3. 3 Hypothesis: \(9^m - 1 = 8j\), so \(9^m = 8j + 1\).
  4. ✓ Step: \(9^{m+1} - 1 = 9(8j+1) - 1 = 72j + 8 = 8(9j + 1)\) — divisible by 8. ∎
Tidy the exponent first

Going from \(3^{2m}\) to \(3^{2(m+1)}\) means multiplying by \(3^2\), not by 3 — a very common slip. Collapsing to \(9^n\) at the start removes the trap entirely.

Example 2C

Prove that \(3^{2n+1} + 2^{2n+1}\) is divisible by 5 for all integers \(n \geq 0\).

  1. 1 Base: \(n = 0\): \(3 + 2 = 5\). ✓  (Check \(n=1\) too if you like: \(27 + 8 = 35\).)
  2. 2 Hypothesis: \(3^{2m+1} + 2^{2m+1} = 5j\) for some integer \(j\).
  3. 3 Step: each exponent rises by 2, so \(3^{2m+3} + 2^{2m+3} = 9 \cdot 3^{2m+1} + 4 \cdot 2^{2m+1}\). The multipliers differ — you cannot factor directly.
  4. 4 The trick: write \(9 = 4 + 5\), so the expression is \(4\big(3^{2m+1} + 2^{2m+1}\big) + 5 \cdot 3^{2m+1}\).
  5. ✓ That is \(4(5j) + 5 \cdot 3^{2m+1} = 5\big(4j + 3^{2m+1}\big)\) — divisible by 5. ∎
When two powers appear

Split the larger multiplier as (the smaller one) + (the divisor). That manufactures a copy of the inductive hypothesis, and whatever is left over already carries the divisor as a factor. This is the standard manoeuvre for any \(a^n + b^n\) divisibility claim.

Example 2D

Prove that \(n^3 - n\) is divisible by 3 for all integers \(n \geq 1\).

  1. 1 Base: \(n = 1\): \(1 - 1 = 0 = 3 \times 0\). ✓  (Zero is divisible by 3 — say so rather than skipping to \(n=2\).)
  2. 2 Hypothesis: \(m^3 - m = 3j\) for some integer \(j\).
  3. 3 Step: \((m+1)^3 - (m+1) = m^3 + 3m^2 + 3m + 1 - m - 1 = \big(m^3 - m\big) + 3m^2 + 3m\).
  4. ✓ \(= 3j + 3(m^2 + m) = 3\big(j + m^2 + m\big)\) — divisible by 3. ∎
Polynomials are easier than powers

Expand \((m+1)^3\), then look for the hypothesis inside the expansion and bracket it off. Everything left over should carry the divisor visibly. No pivoting needed.

Example 2E

Prove that \(n^3 + 5n\) is divisible by 6 for all integers \(n \geq 1\).

  1. 1 Base: \(n = 1\): \(1 + 5 = 6\). ✓
  2. 2 Hypothesis: \(m^3 + 5m = 6j\) for some integer \(j\).
  3. 3 Step: \((m+1)^3 + 5(m+1) = m^3 + 3m^2 + 3m + 1 + 5m + 5 = \big(m^3 + 5m\big) + 3m^2 + 3m + 6\).
  4. 4 \(= 6j + 3\big(m^2 + m\big) + 6\). The leftover is a multiple of 3, but we need a multiple of 6 — one more observation is required.
  5. ✓ \(m^2 + m = m(m+1)\) is a product of consecutive integers, hence even: \(m(m+1) = 2t\). So the total is \(6j + 6t + 6 = 6(j + t + 1)\). ∎
When the leftover is not enough

Getting \(3(m^2+m)\) and stopping is a half-proof. A composite divisor often needs a second fact — here that \(m(m+1)\) is even, which is Example 1B from T3W08. Divisibility by 6 always means checking 2 and 3.

Checkpoint 3 — your turn

Try it! (≈6 min)

Prove by induction: \(7^n - 1\) is divisible by 6 for all integers \(n \geq 1\).

  • Base: \(n=1\): \(7 - 1 = 6\). ✓   Hypothesis: \(7^m - 1 = 6j\), i.e. \(7^m = 6j + 1\).
  • Step: \(7^{m+1} - 1 = 7(6j + 1) - 1 = 42j + 6 = 6(7j + 1)\). ∎
  • Same pivot, new numbers. Say where the hypothesis entered — that's the mark that distinguishes induction from wishful thinking.
Lesson 4 · 2E

Products, inequalities — and the wrap-up

  • Products: multiply the next factor into the hypothesis.
  • Inequality inductions: one honest bound closes the step.
  • Where induction proofs lose marks; the holiday plan.

Induction on products — worked examples

Example 3A

Prove \(\displaystyle\prod_{k=2}^{n} \left(1 - \frac{1}{k}\right) = \frac{1}{n}\) for all \(n \geq 2\).

  1. 1 Base: \(n = 2\): LHS \(= 1 - \tfrac12 = \tfrac12\) = RHS. ✓
  2. 2 Hypothesis: \(\displaystyle\prod_{k=2}^{m}\left(1 - \frac1k\right) = \frac1m\) for some \(m \geq 2\).
  3. ✓ Step: \(\displaystyle\prod_{k=2}^{m+1}\left(1 - \frac{1}{k}\right) = \frac{1}{m}\left(1 - \frac{1}{m+1}\right) = \frac{1}{m} \cdot \frac{m}{m+1} = \frac{1}{m+1}\). ∎
Two tools, one truth

Telescoping (T3W09, Example 5C) finds the formula; induction proves it.

Example 3B

Prove \(\displaystyle\prod_{k=1}^{n} \left(1 + \frac{1}{k}\right) = n + 1\) for all \(n \geq 1\).

  1. 1 Base: \(n = 1\): LHS \(= 1 + 1 = 2\), RHS \(= 1 + 1 = 2\). ✓
  2. 2 Hypothesis: \(\displaystyle\prod_{k=1}^{m}\left(1 + \frac1k\right) = m + 1\) for some \(m \geq 1\).
  3. 3 Step: multiply in the next factor: \((m+1)\left(1 + \dfrac{1}{m+1}\right) = (m+1)\cdot\dfrac{m+2}{m+1}\).
  4. ✓ \(= m + 2 = (m+1) + 1\) — the formula at \(n = m+1\). ∎
The product move

Sums add the next term; products multiply the next factor. Otherwise the framework is identical — base, hypothesis, step, conclusion.

Example 3C

Prove \(\displaystyle\prod_{k=2}^{n} \left(1 - \frac{1}{k^2}\right) = \frac{n+1}{2n}\) for all \(n \geq 2\).

  1. 1 Base: \(n = 2\): LHS \(= 1 - \tfrac14 = \tfrac34\), RHS \(= \dfrac{3}{4}\). ✓
  2. 2 Hypothesis: \(\displaystyle\prod_{k=2}^{m}\left(1 - \frac{1}{k^2}\right) = \frac{m+1}{2m}\) for some \(m \geq 2\).
  3. 3 Step: the next factor is \(1 - \dfrac{1}{(m+1)^2} = \dfrac{(m+1)^2 - 1}{(m+1)^2} = \dfrac{m(m+2)}{(m+1)^2}\).
  4. 4 Multiply: \(\dfrac{m+1}{2m} \cdot \dfrac{m(m+2)}{(m+1)^2} = \dfrac{m+2}{2(m+1)}\) — the \(m\) and one \((m+1)\) cancel.
  5. ✓ That is \(\dfrac{(m+1)+1}{2(m+1)}\) — the formula at \(n = m+1\). ∎
Factor the new term before multiplying

Writing \(1 - \tfrac{1}{(m+1)^2}\) as \(\tfrac{m(m+2)}{(m+1)^2}\) first is what makes the cancellation visible. Multiplying out and hoping is how these proofs stall.

Induction on inequalities — worked examples

Example 4A

Prove that \(2^n > n^2\) for all integers \(n \geq 5\).

  1. 1 Base: \(n = 5\): \(32 > 25\). ✓  (Start at 5, not 1 — the claim is false at \(n = 3\) and \(n = 4\).)
  2. 2 Hypothesis: \(2^m > m^2\) for some \(m \geq 5\). Step: \(2^{m+1} = 2 \cdot 2^m > 2m^2\).
  3. 3 Enough to show \(2m^2 \geq (m+1)^2\): difference \(= m^2 - 2m - 1 = (m-1)^2 - 2 > 0\) for \(m \geq 5\).
  4. ✓ Chaining: \(2^{m+1} > 2m^2 \geq (m+1)^2\). ∎
The shape of every inequality induction

The hypothesis gives the first bound; a small side-inequality — proved honestly, using \(m \geq n_0\) — closes the gap to the target.

Example 4B

Prove that \(n! > 2^n\) for all integers \(n \geq 4\).

  1. 1 Find the right base. \(3! = 6 < 8 = 2^3\), so the claim fails at \(n = 3\). At \(n = 4\): \(24 > 16\). ✓
  2. 2 Hypothesis: \(m! > 2^m\) for some \(m \geq 4\).
  3. 3 Step: \((m+1)! = (m+1) \cdot m! > (m+1) \cdot 2^m\), using the hypothesis and \(m + 1 > 0\).
  4. ✓ Side-inequality: \(m \geq 4\) gives \(m + 1 \geq 5 > 2\), so \((m+1)\cdot 2^m > 2 \cdot 2^m = 2^{m+1}\). Chaining, \((m+1)! > 2^{m+1}\). ∎
Test before you assume

Never take the stated starting value on trust. Evaluating both sides at \(n = 1, 2, 3, 4\) tells you where the claim actually begins — and an induction anchored at the wrong base proves nothing.

Example 4C

Prove Bernoulli's inequality: \((1 + x)^n \geq 1 + nx\) for every real \(x \geq -1\) and every integer \(n \geq 1\).

  1. 1 Base: \(n = 1\): both sides equal \(1 + x\), and \(\geq\) allows equality. ✓
  2. 2 Hypothesis: \((1+x)^m \geq 1 + mx\) for some \(m \geq 1\), with \(x\) fixed and \(x \geq -1\).
  3. 3 Step: multiply both sides by \((1+x)\). This preserves the inequality because \(x \geq -1\) makes \(1 + x \geq 0\) — the only place the hypothesis on \(x\) is used, and the crux of the proof.
  4. 4 \((1+x)^{m+1} \geq (1 + mx)(1 + x) = 1 + (m+1)x + mx^2\).
  5. ✓ \(mx^2 \geq 0\), so \((1+x)^{m+1} \geq 1 + (m+1)x\) — the claim at \(n = m+1\). ∎
Multiplying an inequality

You may multiply both sides by a quantity only once you know its sign. Multiplying by a negative reverses the inequality — which is exactly why \(x \geq -1\) is stated, and why dropping it makes the theorem false.

Example 4D

Prove that \(\displaystyle\sum_{k=1}^{n} \frac{1}{k^2} < 2 - \frac{1}{n}\) for all integers \(n \geq 2\).

  1. 1 Base: \(n = 2\): LHS \(= 1 + \tfrac14 = \tfrac54\), RHS \(= 2 - \tfrac12 = \tfrac32\). And \(\tfrac54 < \tfrac32\). ✓
  2. 2 Hypothesis: \(\displaystyle\sum_{k=1}^{m}\frac{1}{k^2} < 2 - \frac1m\) for some \(m \geq 2\).
  3. 3 Step: \(\displaystyle\sum_{k=1}^{m+1}\frac{1}{k^2} < 2 - \frac1m + \frac{1}{(m+1)^2}\).
  4. 4 Side-inequality: we need \(-\dfrac1m + \dfrac{1}{(m+1)^2} \leq -\dfrac{1}{m+1}\), i.e. \(\dfrac{1}{(m+1)^2} + \dfrac{1}{m+1} \leq \dfrac1m\). Multiplying by \(m(m+1)^2 > 0\) turns this into \(m + m(m+1) \leq (m+1)^2\), that is \(m^2 + 2m \leq m^2 + 2m + 1\) — true.
  5. ✓ So the sum is \(< 2 - \dfrac{1}{m+1}\), the claim at \(n = m+1\). ∎
Why prove a bound at all

No closed form for \(\sum 1/k^2\) is available at this level, yet induction still pins it down: the sum stays below 2 forever. Proving an inequality is often possible where proving an identity is not.

Where induction proofs lose marks

  • No base case — or the wrong one (start where the claim starts, e.g. \(n = 5\) for \(2^n > n^2\)).
  • Hypothesis never used — if your step doesn't invoke \(P(k)\), it isn't induction.
  • Assuming \(P(k+1)\) — working backwards from what you're meant to prove.
  • Missing conclusion — finish with "by the principle of mathematical induction, … for all \(n \geq n_0\)."
Self-check

Underline where the inductive hypothesis enters your step. Can't find it? The proof is broken.
