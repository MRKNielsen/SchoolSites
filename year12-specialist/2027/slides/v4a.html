Vectors and scalars

Vector

A quantity with magnitude and direction, drawn as a directed line segment. A scalar has magnitude only.

Notation

Print uses bold: \(\mathbf{a}\). By hand we write \(\underset{\sim}{a}\). The vector from \(A\) to \(B\) is \(\overrightarrow{AB}\), and the magnitude of \(\mathbf{a}\) is \(|\mathbf{a}|\).

  • Equal vectors have the same length and direction: position does not matter
  • \(k\mathbf{a}\) is parallel to \(\mathbf{a}\), \(|k|\) times as long, reversed if \(k<0\)
  • \(\mathbf{0}\) is the zero vector

Triangle rule: go along \(\mathbf{a}\), then along \(\mathbf{b}\)

Adding and subtracting

Triangle rule

\(\overrightarrow{OA} + \overrightarrow{AB} = \overrightarrow{OB}\). Place the vectors head to tail.

Subtracting

\(\mathbf{a} - \mathbf{b} = \mathbf{a} + (-\mathbf{b})\). Reverse \(\mathbf{b}\), then add.

Moving through a figure

Any path from start to finish gives the same vector. Going against an arrow costs a minus sign.

Going from \(A\) to \(B\) by way of \(O\): \(-\mathbf{a} + \mathbf{b}\)

Position vectors

Position vector

The position vector of a point \(A\) is \(\overrightarrow{OA} = \mathbf{a}\), measured from a fixed origin \(O\).

The one to remember

\[\overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA} = \mathbf{b} - \mathbf{a}\] Finish minus start.

Midpoint

If \(M\) is the midpoint of \(AB\), then \(\overrightarrow{OM} = \tfrac12(\mathbf{a} + \mathbf{b})\).

\(\overrightarrow{AB} = \mathbf{b} - \mathbf{a}\)

I do Vectors in a triangle

Example 1

In triangle \(OAB\), \(\overrightarrow{OA} = \mathbf{a}\) and \(\overrightarrow{OB} = \mathbf{b}\). \(M\) is the midpoint of \(AB\), and \(P\) lies on \(OB\) with \(OP : PB = 2 : 1\). Find \(\overrightarrow{MP}\) in terms of \(\mathbf{a}\) and \(\mathbf{b}\).

  1. 1 \(\overrightarrow{OM} = \tfrac12(\mathbf{a} + \mathbf{b})\)
  2. 2 \(\overrightarrow{OP} = \tfrac23\mathbf{b}\)
  3. 3 \(\overrightarrow{MP} = \overrightarrow{OP} - \overrightarrow{OM} = \tfrac23\mathbf{b} - \tfrac12\mathbf{a} - \tfrac12\mathbf{b}\)
  4. ✓ \(\overrightarrow{MP} = \tfrac16\mathbf{b} - \tfrac12\mathbf{a}\)
Plan

Write the position vector of each end, then use finish minus start.

We do Vectors in a parallelogram

Your turn, with me

\(OABC\) is a parallelogram with \(\overrightarrow{OA} = \mathbf{a}\) and \(\overrightarrow{OC} = \mathbf{c}\). \(D\) lies on \(AB\) with \(AD : DB = 1 : 3\), and \(E\) is the midpoint of \(CB\). Find \(\overrightarrow{DE}\) in terms of \(\mathbf{a}\) and \(\mathbf{c}\).

  1. 1 \(\overrightarrow{AB} = \mathbf{c}\), so \(\overrightarrow{OD} = \mathbf{a} + \tfrac14\mathbf{c}\)
  2. 2 \(\overrightarrow{CB} = \mathbf{a}\), so \(\overrightarrow{OE} = \mathbf{c} + \tfrac12\mathbf{a}\)
  3. 3 \(\overrightarrow{DE} = \overrightarrow{OE} - \overrightarrow{OD} = \mathbf{c} + \tfrac12\mathbf{a} - \mathbf{a} - \tfrac14\mathbf{c}\)
  4. ✓ \(\overrightarrow{DE} = \tfrac34\mathbf{c} - \tfrac12\mathbf{a}\)
Sketch first

Draw the parallelogram and mark \(D\) and \(E\) before writing anything.

Linear dependence

Linearly dependent

Vectors \(\mathbf{a}\), \(\mathbf{b}\) and \(\mathbf{c}\) are linearly dependent if one can be written using the others, for example \(\mathbf{c} = m\mathbf{a} + n\mathbf{b}\). Equivalently \(k\mathbf{a} + l\mathbf{b} + m\mathbf{c} = \mathbf{0}\) with \(k, l, m\) not all zero.

Two vectors

Two non-zero vectors are linearly dependent exactly when they are parallel.

Equating coefficients

If \(\mathbf{a}\) and \(\mathbf{b}\) are not parallel and \(m\mathbf{a} + n\mathbf{b} = p\mathbf{a} + q\mathbf{b}\), then \(m = p\) and \(n = q\).

I do Equating coefficients

Example 2

\(\mathbf{a}\) and \(\mathbf{b}\) are non-zero and not parallel. Find \(m\) and \(n\) if \((2m-1)\mathbf{a} + (n+3)\mathbf{b} = (m+2)\mathbf{a} + (2n-1)\mathbf{b}\).

  1. 1 \(\mathbf{a}\) and \(\mathbf{b}\) are not parallel, so the coefficients match.
  2. 2 \(2m - 1 = m + 2\), so \(m = 3\)
  3. 3 \(n + 3 = 2n - 1\), so \(n = 4\)
  4. ✓ \(m = 3,\ n = 4\)

We do Equating coefficients

Your turn, with me

\(\mathbf{a}\) and \(\mathbf{b}\) are non-zero and not parallel. Find \(p\) and \(q\) if \((p+q)\mathbf{a} + (p-q)\mathbf{b} = 5\mathbf{a} + \mathbf{b}\).

  1. 1 \(p + q = 5\) and \(p - q = 1\)
  2. 2 Adding: \(2p = 6\), so \(p = 3\)
  3. ✓ \(p = 3,\ q = 2\)

I do Showing linear dependence

Example 3

\(\mathbf{a}\) and \(\mathbf{b}\) are not parallel. Let \(\mathbf{u} = \mathbf{a} + 2\mathbf{b}\), \(\mathbf{v} = 2\mathbf{a} - \mathbf{b}\) and \(\mathbf{w} = 4\mathbf{a} + 3\mathbf{b}\). Show that \(\mathbf{u}\), \(\mathbf{v}\) and \(\mathbf{w}\) are linearly dependent.

  1. 1 Try \(\mathbf{w} = x\mathbf{u} + y\mathbf{v} = (x + 2y)\mathbf{a} + (2x - y)\mathbf{b}\)
  2. 2 Match coefficients: \(x + 2y = 4\) and \(2x - y = 3\)
  3. 3 Solving gives \(x = 2,\ y = 1\)
  4. ✓ \(\mathbf{w} = 2\mathbf{u} + \mathbf{v}\), so the three vectors are linearly dependent.

We do Showing linear dependence

Your turn, with me

\(\mathbf{a}\) and \(\mathbf{b}\) are not parallel. Let \(\mathbf{u} = \mathbf{a} - \mathbf{b}\), \(\mathbf{v} = 3\mathbf{a} + \mathbf{b}\) and \(\mathbf{w} = 5\mathbf{a} - \mathbf{b}\). Show that \(\mathbf{u}\), \(\mathbf{v}\) and \(\mathbf{w}\) are linearly dependent.

  1. 1 \(\mathbf{w} = x\mathbf{u} + y\mathbf{v} = (x + 3y)\mathbf{a} + (-x + y)\mathbf{b}\)
  2. 2 \(x + 3y = 5\) and \(-x + y = -1\)
  3. 3 Adding: \(4y = 4\), so \(y = 1\) and \(x = 2\)
  4. ✓ \(\mathbf{w} = 2\mathbf{u} + \mathbf{v}\), so they are linearly dependent.

I do A result about any quadrilateral Exam style

Example 4

\(ABCD\) is a quadrilateral. \(M\) is the midpoint of \(AC\) and \(N\) is the midpoint of \(BD\). Show that \(\overrightarrow{AB} + \overrightarrow{AD} + \overrightarrow{CB} + \overrightarrow{CD} = 4\,\overrightarrow{MN}\).

  1. 1 Use position vectors \(\mathbf{a}, \mathbf{b}, \mathbf{c}, \mathbf{d}\) from an origin \(O\).
  2. 2 LHS \(= (\mathbf{b} - \mathbf{a}) + (\mathbf{d} - \mathbf{a}) + (\mathbf{b} - \mathbf{c}) + (\mathbf{d} - \mathbf{c}) = 2(\mathbf{b} + \mathbf{d}) - 2(\mathbf{a} + \mathbf{c})\)
  3. 3 \(\overrightarrow{OM} = \tfrac12(\mathbf{a} + \mathbf{c})\) and \(\overrightarrow{ON} = \tfrac12(\mathbf{b} + \mathbf{d})\)
  4. 4 \(4\,\overrightarrow{MN} = 4\left[\tfrac12(\mathbf{b} + \mathbf{d}) - \tfrac12(\mathbf{a} + \mathbf{c})\right] = 2(\mathbf{b} + \mathbf{d}) - 2(\mathbf{a} + \mathbf{c})\)
  5. ✓ LHS \(=\) RHS, as required.
"Show that"

Work on each side separately and finish with a clear concluding line.

We do The medians of a triangle Exam style

Your turn, with me

In triangle \(ABC\), the points \(D\), \(E\) and \(F\) are the midpoints of \(BC\), \(CA\) and \(AB\). Show that \(\overrightarrow{AD} + \overrightarrow{BE} + \overrightarrow{CF} = \mathbf{0}\).

  1. 1 \(\overrightarrow{OD} = \tfrac12(\mathbf{b} + \mathbf{c})\), \(\overrightarrow{OE} = \tfrac12(\mathbf{c} + \mathbf{a})\), \(\overrightarrow{OF} = \tfrac12(\mathbf{a} + \mathbf{b})\)
  2. 2 \(\overrightarrow{AD} = \tfrac12(\mathbf{b} + \mathbf{c}) - \mathbf{a}\), and similarly for the others
  3. 3 Sum \(= \tfrac12(2\mathbf{a} + 2\mathbf{b} + 2\mathbf{c}) - (\mathbf{a} + \mathbf{b} + \mathbf{c})\)
  4. ✓ Sum \(= \mathbf{0}\), as required.

You do Check your understanding

In triangle \(OAB\), \(N\) lies on \(AB\) with \(AN : NB = 3 : 1\). Find \(\overrightarrow{ON}\) in terms of \(\mathbf{a}\) and \(\mathbf{b}\).

\(\overrightarrow{ON} = \mathbf{a} + \tfrac34(\mathbf{b} - \mathbf{a}) = \tfrac14\mathbf{a} + \tfrac34\mathbf{b}\)

\(\mathbf{a}\) and \(\mathbf{b}\) are not parallel and \(3\mathbf{a} - 2\mathbf{b} = (k+1)\mathbf{a} + (m-4)\mathbf{b}\). Find \(k\) and \(m\).

\(k = 2,\ m = 2\)

Are \(\mathbf{a} + \mathbf{b}\), \(\mathbf{a} - \mathbf{b}\) and \(3\mathbf{a} + \mathbf{b}\) linearly dependent?

Yes: \(3\mathbf{a} + \mathbf{b} = 2(\mathbf{a} + \mathbf{b}) + (\mathbf{a} - \mathbf{b})\)
