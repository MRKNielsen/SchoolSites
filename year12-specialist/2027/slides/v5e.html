Distance from a point to a plane

Formula

The distance from \(P\) to the plane \(\mathbf{r}\cdot\mathbf{n} = k\) is \[\frac{|\mathbf{p}\cdot\mathbf{n} - k|}{|\mathbf{n}|}\] For \(P(x_1, y_1, z_1)\) and \(ax + by + cz = d\): \[\frac{|ax_1 + by_1 + cz_1 - d|}{\sqrt{a^2 + b^2 + c^2}}\]

Where it comes from

It is the scalar resolute of \(\overrightarrow{AP}\) in the direction of \(\mathbf{n}\), for any point \(A\) in the plane.

The shortest path to a plane runs along the normal

Angles

Line and plane

The angle \(\varphi\) between a line (direction \(\mathbf{d}\)) and a plane (normal \(\mathbf{n}\)): \[\sin\varphi = \frac{|\mathbf{d}\cdot\mathbf{n}|}{|\mathbf{d}|\,|\mathbf{n}|}\]

Two planes

The angle between two planes is the angle between their normals: \[\cos\theta = \frac{|\mathbf{n}_1\cdot\mathbf{n}_2|}{|\mathbf{n}_1|\,|\mathbf{n}_2|}\]

Sine or cosine?

The normal is at \(90^\circ\) to the plane, so a line and plane question swaps cosine for sine.

I do Point to plane

Example 1

Find the distance from \(P(3, -1, 2)\) to the plane \(2x - y + 2z = 3\).

  1. 1 \(\mathbf{n} = 2\mathbf{i} - \mathbf{j} + 2\mathbf{k}\), \(|\mathbf{n}| = 3\)
  2. 2 \(|2(3) - (-1) + 2(2) - 3| = |8|\)
  3. ✓ Distance \(= \dfrac83\)

We do Point to plane

Your turn, with me

Find the distance from \(P(1, 2, -2)\) to the plane \(x - 2y + 2z = 5\).

  1. 1 \(|\mathbf{n}| = 3\)
  2. 2 \(|1 - 4 - 4 - 5| = 12\)
  3. ✓ Distance \(= 4\)

I do A line meeting a plane

Example 2

The line \(\mathbf{r} = \mathbf{i} - \mathbf{k} + t(\mathbf{i} + 2\mathbf{j} + 2\mathbf{k})\) meets the plane \(2x - y + 2z = 8\). Find the point of intersection and the angle between the line and the plane, correct to one decimal place.

  1. 1 On the line: \(x = 1 + t,\ y = 2t,\ z = -1 + 2t\)
  2. 2 Substitute: \(2(1 + t) - 2t + 2(-1 + 2t) = 4t = 8\), so \(t = 2\)
  3. 3 Point: \((3, 4, 3)\)
  4. 4 \(\sin\varphi = \dfrac{|2 - 2 + 4|}{3 \times 3} = \dfrac49\)
  5. ✓ The line meets the plane at \((3, 4, 3)\), at an angle of \(26.4^\circ\).

We do A line meeting a plane

Your turn, with me

The line \(\mathbf{r} = 2\mathbf{i} + \mathbf{j} + t(2\mathbf{i} + \mathbf{j} + 2\mathbf{k})\) meets the plane \(x + 2y + 2z = 12\). Find the point of intersection and the angle between the line and the plane, correct to one decimal place.

  1. 1 \((2 + 2t) + 2(1 + t) + 2(2t) = 4 + 8t = 12\), so \(t = 1\)
  2. 2 Point: \((4, 2, 2)\)
  3. 3 \(\sin\varphi = \dfrac{|2 + 2 + 4|}{3 \times 3} = \dfrac89\)
  4. ✓ \((4, 2, 2)\), at an angle of \(62.7^\circ\)

I do Two planes

Example 3

For the planes \(x + y - z = 2\) and \(2x + y + z = 7\), find the acute angle between them and a vector equation of their line of intersection.

  1. 1 \(\cos\theta = \dfrac{|2 + 1 - 1|}{\sqrt3\,\sqrt6} = \dfrac{2}{3\sqrt2} = \dfrac{\sqrt2}{3}\), so \(\theta \approx 61.9^\circ\)
  2. 2 Direction of the line: \(\mathbf{n}_1 \times \mathbf{n}_2 = (1 + 1)\mathbf{i} - (1 + 2)\mathbf{j} + (1 - 2)\mathbf{k} = 2\mathbf{i} - 3\mathbf{j} - \mathbf{k}\)
  3. 3 A point: let \(y = 0\). Then \(x - z = 2\) and \(2x + z = 7\), so \(x = 3,\ z = 1\)
  4. ✓ \(\theta \approx 61.9^\circ\) and \(\mathbf{r} = 3\mathbf{i} + \mathbf{k} + t(2\mathbf{i} - 3\mathbf{j} - \mathbf{k})\)
Why the cross product?

The line lies in both planes, so it is perpendicular to both normals.

We do Two planes

Your turn, with me

For the planes \(x - y + 2z = 3\) and \(2x + y - z = 3\), find the acute angle between them and a vector equation of their line of intersection.

  1. 1 \(\cos\theta = \dfrac{|2 - 1 - 2|}{\sqrt6\,\sqrt6} = \dfrac16\), so \(\theta \approx 80.4^\circ\)
  2. 2 Direction: \(\mathbf{n}_1 \times \mathbf{n}_2 = (1 - 2)\mathbf{i} - (-1 - 4)\mathbf{j} + (1 + 2)\mathbf{k} = -\mathbf{i} + 5\mathbf{j} + 3\mathbf{k}\)
  3. 3 A point: let \(z = 0\). Then \(x - y = 3\) and \(2x + y = 3\), so \(x = 2,\ y = -1\)
  4. ✓ \(\theta \approx 80.4^\circ\) and \(\mathbf{r} = 2\mathbf{i} - \mathbf{j} + t(-\mathbf{i} + 5\mathbf{j} + 3\mathbf{k})\)

I do Distance between skew lines Exam style

Example 4

Find the shortest distance between the skew lines \(\mathbf{r} = \mathbf{i} + 2\mathbf{k} + \lambda(2\mathbf{i} + \mathbf{j} - \mathbf{k})\) and \(\mathbf{r} = 3\mathbf{j} + \mathbf{k} + \mu(\mathbf{i} - \mathbf{j} + 2\mathbf{k})\).

  1. 1 A vector perpendicular to both lines: \(\mathbf{n} = \mathbf{d}_1 \times \mathbf{d}_2 = (2 - 1)\mathbf{i} - (4 + 1)\mathbf{j} + (-2 - 1)\mathbf{k} = \mathbf{i} - 5\mathbf{j} - 3\mathbf{k}\)
  2. 2 Take \(A(1, 0, 2)\) on the first line and \(B(0, 3, 1)\) on the second: \(\overrightarrow{AB} = -\mathbf{i} + 3\mathbf{j} - \mathbf{k}\)
  3. 3 Distance \(= \dfrac{|\overrightarrow{AB}\cdot\mathbf{n}|}{|\mathbf{n}|} = \dfrac{|-1 - 15 + 3|}{\sqrt{35}}\)
  4. ✓ Distance \(= \dfrac{13}{\sqrt{35}} = \dfrac{13\sqrt{35}}{35}\)
Idea

Resolve any vector joining the two lines onto the common perpendicular.

We do Distance between skew lines Exam style

Your turn, with me

Find the shortest distance between the skew lines \(\mathbf{r} = 2\mathbf{i} + \mathbf{j} + \lambda(\mathbf{i} + \mathbf{j} + \mathbf{k})\) and \(\mathbf{r} = \mathbf{i} + 3\mathbf{k} + \mu(2\mathbf{i} - \mathbf{j} + \mathbf{k})\).

  1. 1 \(\mathbf{n} = \mathbf{d}_1 \times \mathbf{d}_2 = (1 + 1)\mathbf{i} - (1 - 2)\mathbf{j} + (-1 - 2)\mathbf{k} = 2\mathbf{i} + \mathbf{j} - 3\mathbf{k}\)
  2. 2 \(A(2, 1, 0)\), \(B(1, 0, 3)\): \(\overrightarrow{AB} = -\mathbf{i} - \mathbf{j} + 3\mathbf{k}\)
  3. 3 Distance \(= \dfrac{|-2 - 1 - 9|}{\sqrt{14}} = \dfrac{12}{\sqrt{14}}\)
  4. ✓ Distance \(= \dfrac{6\sqrt{14}}{7}\)
