Components in three dimensions

Unit vectors

\(\mathbf{i}\), \(\mathbf{j}\) and \(\mathbf{k}\) are vectors of length 1 along the positive \(x\), \(y\) and \(z\) axes.

Position vector

The point \(P(x, y, z)\) has position vector \(\overrightarrow{OP} = x\mathbf{i} + y\mathbf{j} + z\mathbf{k}\).

Working in components

Add, subtract and scale one component at a time. For points \(A\) and \(B\): \(\overrightarrow{AB} = \mathbf{b} - \mathbf{a}\).

\(\mathbf{r} = x\mathbf{i} + y\mathbf{j} + z\mathbf{k}\)

Magnitude and unit vectors

Magnitude

If \(\mathbf{a} = a_1\mathbf{i} + a_2\mathbf{j} + a_3\mathbf{k}\), then \[|\mathbf{a}| = \sqrt{a_1^2 + a_2^2 + a_3^2}\]

Unit vector

The unit vector in the direction of \(\mathbf{a}\) is \[\hat{\mathbf{a}} = \frac{1}{|\mathbf{a}|}\,\mathbf{a}\]

Parallel

\(\mathbf{a}\) and \(\mathbf{b}\) are parallel when \(\mathbf{a} = k\mathbf{b}\) for some real \(k \ne 0\): every component is scaled by the same \(k\).

I do From points to a vector

Example 1

Points \(A(2, -1, 4)\) and \(B(5, 3, -8)\) are given. Find \(\overrightarrow{AB}\), \(|\overrightarrow{AB}|\) and the unit vector in the direction of \(\overrightarrow{AB}\).

  1. 1 \(\overrightarrow{AB} = \mathbf{b} - \mathbf{a} = (5-2)\mathbf{i} + (3+1)\mathbf{j} + (-8-4)\mathbf{k} = 3\mathbf{i} + 4\mathbf{j} - 12\mathbf{k}\)
  2. 2 \(|\overrightarrow{AB}| = \sqrt{9 + 16 + 144} = \sqrt{169} = 13\)
  3. ✓ Unit vector \(= \tfrac{1}{13}(3\mathbf{i} + 4\mathbf{j} - 12\mathbf{k})\)

  1. 1 \(\overrightarrow{AB} = 2\mathbf{i} - 6\mathbf{j} + 3\mathbf{k}\)

  3. ✓ Unit vector \(= \tfrac17(2\mathbf{i} - 6\mathbf{j} + 3\mathbf{k})\)

I do Parallel vectors with unknowns

Example 2

The vectors \(2\mathbf{i} + m\mathbf{j} - 6\mathbf{k}\) and \(n\mathbf{i} + 3\mathbf{j} + 9\mathbf{k}\) are parallel. Find \(m\) and \(n\).

  1. 1 Parallel, so \(2\mathbf{i} + m\mathbf{j} - 6\mathbf{k} = \lambda(n\mathbf{i} + 3\mathbf{j} + 9\mathbf{k})\)
  2. 2 \(\mathbf{k}\): \(-6 = 9\lambda\), so \(\lambda = -\tfrac23\)
  3. 3 \(\mathbf{j}\): \(m = 3\lambda = -2\)
  4. 4 \(\mathbf{i}\): \(2 = -\tfrac23 n\), so \(n = -3\)
  5. ✓ \(m = -2,\ n = -3\)
Start where you can

Use the component with no unknown to find the scale factor first.

We do Parallel vectors with unknowns

Your turn, with me

The vectors \(m\mathbf{i} - 4\mathbf{j} + 2\mathbf{k}\) and \(6\mathbf{i} + 8\mathbf{j} + n\mathbf{k}\) are parallel. Find \(m\) and \(n\).

  1. 1 \(\mathbf{j}\): \(-4 = 8\lambda\), so \(\lambda = -\tfrac12\)
  2. 2 \(\mathbf{i}\): \(m = 6\lambda = -3\)
  3. 3 \(\mathbf{k}\): \(2 = -\tfrac12 n\), so \(n = -4\)
  4. ✓ \(m = -3,\ n = -4\)

The angle a vector makes with an axis

Direction angles

If \(\mathbf{a} = a_1\mathbf{i} + a_2\mathbf{j} + a_3\mathbf{k}\) makes angles \(\alpha\), \(\beta\), \(\gamma\) with the positive \(x\), \(y\) and \(z\) axes, then \[\cos\alpha = \frac{a_1}{|\mathbf{a}|},\quad \cos\beta = \frac{a_2}{|\mathbf{a}|},\quad \cos\gamma = \frac{a_3}{|\mathbf{a}|}\]

Check

A negative component gives an obtuse angle with that axis.

I do Angles with the axes

Example 3

Find the angle that \(\mathbf{a} = \mathbf{i} + \sqrt2\,\mathbf{j} - \mathbf{k}\) makes with each of the positive axes.

  1. 1 \(|\mathbf{a}| = \sqrt{1 + 2 + 1} = 2\)
  2. 2 \(\cos\alpha = \tfrac12\), so \(\alpha = 60^\circ\)
  3. 3 \(\cos\beta = \tfrac{\sqrt2}{2}\), so \(\beta = 45^\circ\)
  4. 4 \(\cos\gamma = -\tfrac12\), so \(\gamma = 120^\circ\)
  5. ✓ \(60^\circ\) with the \(x\)-axis, \(45^\circ\) with the \(y\)-axis, \(120^\circ\) with the \(z\)-axis

We do Angles with the axes

Your turn, with me

Find, correct to one decimal place, the angle that \(\mathbf{a} = 2\mathbf{i} - 2\mathbf{j} + \mathbf{k}\) makes with the positive \(x\)-axis and with the positive \(z\)-axis.

  1. 1 \(|\mathbf{a}| = \sqrt{4 + 4 + 1} = 3\)
  2. 2 \(\cos\alpha = \tfrac23\), so \(\alpha \approx 48.2^\circ\)
  3. ✓ \(48.2^\circ\) with the \(x\)-axis; \(\cos\gamma = \tfrac13\) gives \(70.5^\circ\) with the \(z\)-axis

I do Linear dependence in three dimensions Exam style

Example 4

Let \(\mathbf{a} = 2\mathbf{i} - \mathbf{j} + \mathbf{k}\), \(\mathbf{b} = \mathbf{i} + 2\mathbf{j} - 3\mathbf{k}\) and \(\mathbf{c} = 4\mathbf{i} - 7\mathbf{j} + t\mathbf{k}\). Find the value of \(t\) for which \(\mathbf{a}\), \(\mathbf{b}\) and \(\mathbf{c}\) are linearly dependent.

  1. 1 \(\mathbf{a}\) and \(\mathbf{b}\) are not parallel, so we need \(\mathbf{c} = p\mathbf{a} + q\mathbf{b}\).
  2. 2 \(\mathbf{i}\): \(2p + q = 4\)   and   \(\mathbf{j}\): \(-p + 2q = -7\)
  3. 3 Solving: \(p = 3,\ q = -2\)
  4. 4 \(\mathbf{k}\): \(t = p - 3q = 3 + 6\)
  5. ✓ \(t = 9\)
Three equations, two unknowns

Solve two of them, then the third fixes \(t\).

We do Linear dependence in three dimensions Exam style

Your turn, with me

Let \(\mathbf{a} = \mathbf{i} + \mathbf{j} - 2\mathbf{k}\), \(\mathbf{b} = 3\mathbf{i} - \mathbf{j} + \mathbf{k}\) and \(\mathbf{c} = 5\mathbf{i} + \mathbf{j} + t\mathbf{k}\). Find the value of \(t\) for which \(\mathbf{a}\), \(\mathbf{b}\) and \(\mathbf{c}\) are linearly dependent.

  1. 1 \(\mathbf{c} = p\mathbf{a} + q\mathbf{b}\)
  2. 2 \(p + 3q = 5\) and \(p - q = 1\), so \(q = 1,\ p = 2\)
  3. 3 \(t = -2p + q = -4 + 1\)
  4. ✓ \(t = -3\)
