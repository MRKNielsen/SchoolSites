Vector equations of planes

Normals, and planes through points and lines

Textbook: Cambridge Specialist Mathematics 3&4, Section 5D

The equation of a plane

Normal

A normal vector \(\mathbf{n}\) is perpendicular to every direction in the plane.

Vector equation

For a plane through \(A\) with normal \(\mathbf{n}\): \[(\mathbf{r} - \mathbf{a})\cdot\mathbf{n} = 0 \quad\text{or}\quad \mathbf{r}\cdot\mathbf{n} = \mathbf{a}\cdot\mathbf{n}\]

Cartesian equation

With \(\mathbf{n} = a\mathbf{i} + b\mathbf{j} + c\mathbf{k}\): \[ax + by + cz = d,\quad d = \mathbf{a}\cdot\mathbf{n}\]

\(\mathbf{r} - \mathbf{a}\) lies in the plane, so it is perpendicular to \(\mathbf{n}\)

Finding a normal

Two directions in the plane

If \(\mathbf{u}\) and \(\mathbf{v}\) are non-parallel vectors in the plane, then \(\mathbf{n} = \mathbf{u} \times \mathbf{v}\) is a normal.

  • Three points \(A\), \(B\), \(C\): use \(\overrightarrow{AB} \times \overrightarrow{AC}\)
  • A line and a point \(A\) not on it: use the direction \(\mathbf{d}\) and a vector from \(A\) to the line
  • Two intersecting lines: use \(\mathbf{d}_1 \times \mathbf{d}_2\)
Reading an equation

In \(2x - y + 3z = 5\), the coefficients give the normal \(2\mathbf{i} - \mathbf{j} + 3\mathbf{k}\).

I do Point and normal

Example 1

Find the Cartesian equation of the plane through \(A(1, 4, -2)\) with normal \(\mathbf{n} = 2\mathbf{i} - \mathbf{j} + 3\mathbf{k}\).

  1. 1 \(\mathbf{r}\cdot\mathbf{n} = \mathbf{a}\cdot\mathbf{n}\)
  2. 2 \(\mathbf{a}\cdot\mathbf{n} = 2 - 4 - 6 = -8\)
  3. ✓ \(2x - y + 3z = -8\)

  1. 1 \(\mathbf{a}\cdot\mathbf{n} = 2 - 3 - 10 = -11\)
  2. ✓ \(x + 3y - 2z = -11\)

I do Plane through three points

Example 2

Find the Cartesian equation of the plane through \(A(1, 0, 2)\), \(B(3, 1, 1)\) and \(C(2, -1, 4)\).

  1. 1 \(\overrightarrow{AB} = 2\mathbf{i} + \mathbf{j} - \mathbf{k}\) and \(\overrightarrow{AC} = \mathbf{i} - \mathbf{j} + 2\mathbf{k}\)
  2. 2 \(\mathbf{n} = \overrightarrow{AB} \times \overrightarrow{AC} = \mathbf{i} - 5\mathbf{j} - 3\mathbf{k}\)
  3. 3 \(\mathbf{a}\cdot\mathbf{n} = 1 - 0 - 6 = -5\)
  4. ✓ \(x - 5y - 3z = -5\)
Check

Substitute \(B\): \(3 - 5 - 3 = -5\) ✓   and \(C\): \(2 + 5 - 12 = -5\) ✓

We do Plane through three points

Your turn, with me

Find the Cartesian equation of the plane through \(A(0, 1, 1)\), \(B(2, 2, 0)\) and \(C(1, 3, 3)\).

  1. 1 \(\overrightarrow{AB} = 2\mathbf{i} + \mathbf{j} - \mathbf{k}\) and \(\overrightarrow{AC} = \mathbf{i} + 2\mathbf{j} + 2\mathbf{k}\)
  2. 2 \(\mathbf{n} = 4\mathbf{i} - 5\mathbf{j} + 3\mathbf{k}\)
  3. 3 \(\mathbf{a}\cdot\mathbf{n} = 0 - 5 + 3 = -2\)
  4. ✓ \(4x - 5y + 3z = -2\)

I do Plane containing two lines

Example 3

The lines \(\mathbf{r} = \mathbf{i} + 2\mathbf{j} + \lambda(\mathbf{i} + \mathbf{j} + 2\mathbf{k})\) and \(\mathbf{r} = 2\mathbf{i} + 6\mathbf{j} + 3\mathbf{k} + \mu(\mathbf{i} - 2\mathbf{j} + \mathbf{k})\) intersect. Find the Cartesian equation of the plane containing both lines.

  1. 1 \(\mathbf{n} = \mathbf{d}_1 \times \mathbf{d}_2 = (1 + 4)\mathbf{i} - (1 - 2)\mathbf{j} + (-2 - 1)\mathbf{k} = 5\mathbf{i} + \mathbf{j} - 3\mathbf{k}\)
  2. 2 Use the point \((1, 2, 0)\): \(5 + 2 - 0 = 7\)
  3. ✓ \(5x + y - 3z = 7\)
Check

\((2, 6, 3)\) from the second line: \(10 + 6 - 9 = 7\) ✓

We do Plane containing two lines

Your turn, with me

The lines \(\mathbf{r} = 2\mathbf{i} - \mathbf{j} + 3\mathbf{k} + \lambda(\mathbf{i} + 2\mathbf{j} - \mathbf{k})\) and \(\mathbf{r} = 3\mathbf{i} + 7\mathbf{j} - 3\mathbf{k} + \mu(2\mathbf{i} - 2\mathbf{j} + 3\mathbf{k})\) intersect. Find the Cartesian equation of the plane containing both lines.

  1. 1 \(\mathbf{n} = (6 - 2)\mathbf{i} - (3 + 2)\mathbf{j} + (-2 - 4)\mathbf{k} = 4\mathbf{i} - 5\mathbf{j} - 6\mathbf{k}\)
  2. 2 Use \((2, -1, 3)\): \(8 + 5 - 18 = -5\)
  3. ✓ \(4x - 5y - 6z = -5\)

I do Plane containing a line and a point Exam style

Example 4

Find the Cartesian equation of the plane that contains the point \(A(2, 0, 1)\) and the line \(\mathbf{r} = \mathbf{i} + \mathbf{j} + 3\mathbf{k} + t(2\mathbf{i} - \mathbf{j} + \mathbf{k})\).

  1. 1 \(B(1, 1, 3)\) is on the line, so \(\overrightarrow{AB} = -\mathbf{i} + \mathbf{j} + 2\mathbf{k}\) lies in the plane.
  2. 2 \(\mathbf{n} = \overrightarrow{AB} \times \mathbf{d} = (1 + 2)\mathbf{i} - (-1 - 4)\mathbf{j} + (1 - 2)\mathbf{k} = 3\mathbf{i} + 5\mathbf{j} - \mathbf{k}\)
  3. 3 \(\mathbf{a}\cdot\mathbf{n} = 6 + 0 - 1 = 5\)
  4. ✓ \(3x + 5y - z = 5\)
Check

\(B\): \(3 + 5 - 3 = 5\) ✓   and \(\mathbf{n}\cdot\mathbf{d} = 6 - 5 - 1 = 0\) ✓

We do Plane containing a line and a point Exam style

Your turn, with me

Find the Cartesian equation of the plane that contains the point \(A(1, 1, 0)\) and the line \(\mathbf{r} = 2\mathbf{i} + \mathbf{k} + t(\mathbf{i} + 2\mathbf{j} - \mathbf{k})\).

  1. 1 \(B(2, 0, 1)\) is on the line, so \(\overrightarrow{AB} = \mathbf{i} - \mathbf{j} + \mathbf{k}\)
  2. 2 \(\mathbf{n} = \overrightarrow{AB} \times \mathbf{d} = (1 - 2)\mathbf{i} - (-1 - 1)\mathbf{j} + (2 + 1)\mathbf{k} = -\mathbf{i} + 2\mathbf{j} + 3\mathbf{k}\)
  3. 3 \(\mathbf{a}\cdot\mathbf{n} = -1 + 2 = 1\)
  4. ✓ \(-x + 2y + 3z = 1\), or \(x - 2y - 3z = -1\)
