1A Circular functions

Remember

Exact values come from the unit circle. For equations, find the base angle, then every solution in the domain.

Solve \(2\cos(2x) = 1\) for \(x \in [0, \pi]\).

\(2x = \tfrac{\pi}{3}, \tfrac{5\pi}{3}\), so \(x = \tfrac{\pi}{6}, \tfrac{5\pi}{6}\)

Find the exact value of \(\tan\left(\tfrac{5\pi}{6}\right)\).

\(-\tfrac{1}{\sqrt3}\)

1B Sine and cosine rules

Remember

Cosine rule: \(c^2 = a^2 + b^2 - 2ab\cos C\). Area \(= \tfrac12 ab\sin C\). Sine rule: \(\dfrac{a}{\sin A} = \dfrac{b}{\sin B}\).

A triangle has sides 7 and 8 with an included angle of \(120^\circ\). Find the third side.

\(c^2 = 49 + 64 + 56 = 169\), so \(c = 13\)

Find the exact area of the same triangle.

\(\tfrac12 \times 7 \times 8 \times \tfrac{\sqrt3}{2} = 14\sqrt3\)

1C Sequences and series

Remember

Geometric: \(t_n = ar^{n-1}\), \(S_n = \dfrac{a(r^n - 1)}{r - 1}\). A recurrence \(t_{n+1} = rt_n + d\) settles where \(t = rt + d\).

Find the sum of the first 8 terms of \(3, 6, 12, \ldots\)

\(3(2^8 - 1) = 765\)

Find the steady-state value of \(t_{n+1} = 0.8t_n + 10\).

\(t = 0.8t + 10\), so \(t = 50\)

1D The modulus function

Remember

\(|x|\) is the distance from zero. \(|f(x)| > a\) means \(f(x) > a\) or \(f(x) < -a\).

Solve \(|3x - 2| > 4\).

\(x > 2\) or \(x < -\tfrac23\)

How many solutions does \(|x^2 - 1| = 1\) have?

\(x^2 = 2\) or \(x^2 = 0\): three solutions

1E–1F Circles, ellipses and hyperbolas

Remember

Ellipse: \(\dfrac{(x-h)^2}{a^2} + \dfrac{(y-k)^2}{b^2} = 1\), centre \((h, k)\). Hyperbola \(\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1\) has asymptotes \(y = \pm\dfrac{b}{a}x\).

State the centre of \(\dfrac{(x+2)^2}{9} + \dfrac{(y-1)^2}{4} = 1\).

\((-2, 1)\)

Find the asymptotes of \(\dfrac{x^2}{16} - \dfrac{y^2}{9} = 1\).

\(y = \pm\tfrac34 x\)

1G Parametric equations

Remember

Eliminate the parameter to get the Cartesian equation. The domain of the parameter restricts the curve.

Find the Cartesian equation of \(x = 2t - 1,\ y = 4t^2\).

\(t = \tfrac{x+1}{2}\), so \(y = (x + 1)^2\)

Describe \(x = 4\cos t,\ y = 4\sin t\) for \(t \in [\pi, 2\pi]\).

The lower half of the circle \(x^2 + y^2 = 16\)

1H Algorithms and pseudocode

Remember

Trace a loop with a table: one row per pass, one column per variable.

sum ← 0
for i from 1 to 5
  sum ← sum + 2^(i − 1)
print sum

\(1 + 2 + 4 + 8 + 16 = 31\)

n ← 100, count ← 0
while n > 10
  n ← n ÷ 2, count ← count + 1
print count

\(100 \to 50 \to 25 \to 12.5 \to 6.25\): prints 4

Vectors: the basics

Remember

\(|x\mathbf{i} + y\mathbf{j} + z\mathbf{k}| = \sqrt{x^2 + y^2 + z^2}\). Parallel vectors are multiples of each other.

Find \(|3\mathbf{i} - 4\mathbf{j} + 12\mathbf{k}|\).

\(\sqrt{9 + 16 + 144} = 13\)

\(2\mathbf{i} + m\mathbf{j}\) is parallel to \(-\mathbf{i} + 2\mathbf{j}\). Find \(m\).

Scale factor \(-2\), so \(m = -4\)

Vectors: the scalar product

Remember

\(\mathbf{a}\cdot\mathbf{b} = a_1b_1 + a_2b_2 + a_3b_3 = |\mathbf{a}|\,|\mathbf{b}|\cos\theta\)

Find \((\mathbf{i} + 2\mathbf{j} + 2\mathbf{k})\cdot(2\mathbf{i} - \mathbf{j} + 2\mathbf{k})\).

\(2 - 2 + 4 = 4\)

Find the cosine of the angle between those two vectors.

Both have length 3, so \(\cos\theta = \tfrac49\)

Calculus from Methods Units 1 and 2

Remember

\(\dfrac{d}{dx}\left(x^n\right) = nx^{n-1}\). Stationary points occur where \(\dfrac{dy}{dx} = 0\).

Differentiate \(y = x^4 - \dfrac{3}{x}\).

\(\dfrac{dy}{dx} = 4x^3 + \dfrac{3}{x^2}\)

Find and classify the stationary points of \(y = x^3 - 12x\).

\(3x^2 - 12 = 0\): local maximum \((-2, 16)\), local minimum \((2, -16)\)
