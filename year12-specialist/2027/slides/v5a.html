The vector equation of a line

Line

The line through the point \(A\) parallel to \(\mathbf{d}\) is \[\mathbf{r} = \mathbf{a} + t\mathbf{d},\quad t \in \mathbb{R}\] Each value of \(t\) gives one point on the line.

Through two points

Use \(\mathbf{d} = \overrightarrow{AB} = \mathbf{b} - \mathbf{a}\), so \(\mathbf{r} = \mathbf{a} + t(\mathbf{b} - \mathbf{a})\).

Not unique

Any point on the line can be the starting point, and any multiple of \(\mathbf{d}\) is a direction.

Start at \(A\), travel \(t\) lots of \(\mathbf{d}\)

Three forms of the same line

Vector

\(\mathbf{r} = a_1\mathbf{i} + a_2\mathbf{j} + a_3\mathbf{k} + t(d_1\mathbf{i} + d_2\mathbf{j} + d_3\mathbf{k})\)

Parametric

\(x = a_1 + d_1t,\quad y = a_2 + d_2t,\quad z = a_3 + d_3t\)

Cartesian

Make \(t\) the subject in each: \[\frac{x - a_1}{d_1} = \frac{y - a_2}{d_2} = \frac{z - a_3}{d_3}\]

Reading a Cartesian form

Numerators give a point (change the signs). Denominators give the direction.

I do A line through two points

Example 1

Find a vector equation of the line through \(A(2, -1, 3)\) and \(B(5, 1, -1)\). Does \(P(11, 5, -9)\) lie on the line?

  1. 1 \(\mathbf{d} = \overrightarrow{AB} = 3\mathbf{i} + 2\mathbf{j} - 4\mathbf{k}\)
  2. 2 \(\mathbf{r} = 2\mathbf{i} - \mathbf{j} + 3\mathbf{k} + t(3\mathbf{i} + 2\mathbf{j} - 4\mathbf{k})\)
  3. 3 \(x\): \(2 + 3t = 11\), so \(t = 3\)
  4. 4 Check: \(y = -1 + 6 = 5\) ✓ and \(z = 3 - 12 = -9\) ✓
  5. ✓ \(\mathbf{r} = 2\mathbf{i} - \mathbf{j} + 3\mathbf{k} + t(3\mathbf{i} + 2\mathbf{j} - 4\mathbf{k})\), and \(P\) lies on the line (\(t = 3\)).
On the line?

The same \(t\) must work for all three coordinates.

We do A line through two points

Your turn, with me

Find a vector equation of the line through \(A(1, 4, -2)\) and \(B(3, 1, 2)\). Does \(P(7, -5, 10)\) lie on the line?

  1. 1 \(\mathbf{d} = 2\mathbf{i} - 3\mathbf{j} + 4\mathbf{k}\)
  2. 2 \(\mathbf{r} = \mathbf{i} + 4\mathbf{j} - 2\mathbf{k} + t(2\mathbf{i} - 3\mathbf{j} + 4\mathbf{k})\)
  3. 3 \(x\): \(1 + 2t = 7\), so \(t = 3\). Then \(y = 4 - 9 = -5\) ✓, \(z = -2 + 12 = 10\) ✓
  4. ✓ \(P\) lies on the line (\(t = 3\)).

I do From Cartesian form

Example 2

A line has Cartesian equation \(\dfrac{x + 1}{2} = \dfrac{y - 3}{-1} = \dfrac{z - 8}{4}\). Write it in vector form and find where it meets the \(xy\)-plane.

  1. 1 Point \((-1, 3, 8)\), direction \(2\mathbf{i} - \mathbf{j} + 4\mathbf{k}\)
  2. 2 \(\mathbf{r} = -\mathbf{i} + 3\mathbf{j} + 8\mathbf{k} + t(2\mathbf{i} - \mathbf{j} + 4\mathbf{k})\)
  3. 3 On the \(xy\)-plane \(z = 0\): \(8 + 4t = 0\), so \(t = -2\)
  4. ✓ The line meets the \(xy\)-plane at \((-5, 5, 0)\).

We do From Cartesian form

Your turn, with me

A line has Cartesian equation \(\dfrac{x - 4}{3} = \dfrac{y + 2}{2} = \dfrac{z - 6}{-2}\). Write it in vector form and find where it meets the \(xy\)-plane.

  1. 1 \(\mathbf{r} = 4\mathbf{i} - 2\mathbf{j} + 6\mathbf{k} + t(3\mathbf{i} + 2\mathbf{j} - 2\mathbf{k})\)
  2. 2 \(z = 0\): \(6 - 2t = 0\), so \(t = 3\)
  3. ✓ \((13, 4, 0)\)

I do Distance from a point to a line

Example 3

Find the distance from \(P(5, 3, 0)\) to the line \(\mathbf{r} = \mathbf{i} + 2\mathbf{k} + t(2\mathbf{i} + \mathbf{j} - 2\mathbf{k})\).

  1. 1 A general point on the line is \(Q(1 + 2t,\ t,\ 2 - 2t)\).
  2. 2 \(\overrightarrow{PQ} = (2t - 4)\mathbf{i} + (t - 3)\mathbf{j} + (2 - 2t)\mathbf{k}\)
  3. 3 Closest when \(\overrightarrow{PQ}\cdot\mathbf{d} = 0\): \(2(2t - 4) + (t - 3) - 2(2 - 2t) = 9t - 15 = 0\)
  4. 4 \(t = \tfrac53\), so \(\overrightarrow{PQ} = -\tfrac23\mathbf{i} - \tfrac43\mathbf{j} - \tfrac43\mathbf{k}\)
  5. ✓ Distance \(= \tfrac13\sqrt{4 + 16 + 16} = 2\)
Idea

The shortest path from \(P\) to the line is perpendicular to the line.

We do Distance from a point to a line

Your turn, with me

Find the distance from \(P(3, 6, 4)\) to the line \(\mathbf{r} = 2\mathbf{i} + \mathbf{j} - \mathbf{k} + t(\mathbf{i} + 2\mathbf{j} + 2\mathbf{k})\).

  1. 1 \(\overrightarrow{PQ} = (t - 1)\mathbf{i} + (2t - 5)\mathbf{j} + (2t - 5)\mathbf{k}\)
  2. 2 \(\overrightarrow{PQ}\cdot\mathbf{d} = (t - 1) + 2(2t - 5) + 2(2t - 5) = 9t - 21 = 0\), so \(t = \tfrac73\)
  3. 3 \(\overrightarrow{PQ} = \tfrac43\mathbf{i} - \tfrac13\mathbf{j} - \tfrac13\mathbf{k}\)
  4. ✓ Distance \(= \tfrac13\sqrt{18} = \sqrt2\)

I do Points a given distance along a line Exam style

Example 4

Find the coordinates of the points on the line \(\mathbf{r} = \mathbf{i} - 2\mathbf{j} + 4\mathbf{k} + t(2\mathbf{i} + \mathbf{j} - 2\mathbf{k})\) that are 6 units from the point \(A(1, -2, 4)\).

  1. 1 \(A\) is the point where \(t = 0\), so the distance from \(A\) is \(|t\,\mathbf{d}|\).
  2. 2 \(|\mathbf{d}| = \sqrt{4 + 1 + 4} = 3\), so \(3|t| = 6\) and \(t = \pm 2\)
  3. 3 \(t = 2\): \((5, 0, 0)\)   \(t = -2\): \((-3, -4, 8)\)
  4. ✓ \((5, 0, 0)\) and \((-3, -4, 8)\)
Two answers

You can travel either way along the line.

Your turn, with me

Find the coordinates of the points on the line \(\mathbf{r} = 3\mathbf{i} + \mathbf{j} - 2\mathbf{k} + t(\mathbf{i} - 2\mathbf{j} + 2\mathbf{k})\) that are 9 units from the point \(A(3, 1, -2)\).

  1. 1 \(|\mathbf{d}| = 3\), so \(3|t| = 9\) and \(t = \pm 3\)
  2. ✓ \((6, -5, 4)\) and \((0, 7, -8)\)

Find the Cartesian equation of the line through \((2, 0, -1)\) and \((4, 3, 1)\).

\(\dfrac{x - 2}{2} = \dfrac{y}{3} = \dfrac{z + 1}{2}\)

Does \((4, -1, 2)\) lie on \(\mathbf{r} = \mathbf{i} + 2\mathbf{j} + 3\mathbf{k} + t(2\mathbf{i} - \mathbf{j} + \mathbf{k})\)?

No: \(x\) needs \(t = \tfrac32\), but then \(y = \tfrac12\)

Where does \(\mathbf{r} = \mathbf{i} + 2\mathbf{j} + 3\mathbf{k} + t(2\mathbf{i} - \mathbf{j} + \mathbf{k})\) meet the \(yz\)-plane?

\(x = 0\) gives \(t = -\tfrac12\): \(\left(0, \tfrac52, \tfrac52\right)\)
