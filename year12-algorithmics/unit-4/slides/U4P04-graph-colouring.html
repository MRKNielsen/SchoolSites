Graph Colouring

Unit 4 AOS2 · Additional topic 4 of 4 — timetables, clashes and the chromatic number

VCE Algorithmics (HESS) · Northcote High School

The problem

Graph colouring

Assign a colour to every node so that no two adjacent nodes share a colour (a proper colouring), using as few colours as possible.

  • A colouring that uses at most \(k\) colours is a \(k\)-colouring.
  • The fewest colours that work is the graph's chromatic number, \(\chi(G)\).
  • Colours are just labels — "red", "block 2", "register 5", "frequency 3" — the problem only cares which nodes share one.
Two quick lower bounds

Any edge forces \(\chi \ge 2\). Any triangle forces \(\chi \ge 3\) — three nodes all adjacent to each other need three different colours. In general, \(k\) mutually adjacent nodes force \(\chi \ge k\).

Versions and complexity

QuestionClassWhy
Is \(G\) 2-colourable?PBFS, alternating colours; fails exactly when there is an odd cycle. \(O(V + E)\).
Is \(G\) \(k\)-colourable, \(k \ge 3\)?NP-completeeasy to check a colouring; no known fast way to find one
What is \(\chi(G)\)? Find a colouring using \(\chi(G)\) colours.NP-hardat least as hard as every \(k\)-colouring decision
  • Verifying a proposed colouring: for every edge, check its two ends differ — \(O(E)\). That is why the decision version is in NP.
  • The jump from 2 colours (easy) to 3 colours (NP-complete) is a favourite exam point.

Modelling a timetable as colouring

  • Node = a gym program.
  • Edge = some member is enrolled in both, so they clash.
  • Colour = a timetable block.
Think

What is the fewest blocks this gym needs? Find a lower bound first.

The mapping

A proper colouring is a timetable with no clashes: adjacent programs get different blocks. The fewest blocks needed is \(\chi(G)\).

Three blocks is the minimum

  • Lower bound: Yoga, Spin and Pilates form a triangle, so at least 3 blocks.
  • Upper bound: the colouring above uses 3 and every edge joins different blocks.
  • Lower bound meets upper bound, so \(\chi = 3\). On a small graph a triangle is a quick proof; on a large one, finding matching bounds is the hard part.

Recognise the shape

Whenever a question says "these things can't share a … ", reach for graph colouring: things are nodes, conflicts are edges, the shared resource is the colour.

Greedy colouring

Algorithm GreedyColour(G, order):    Foreach v in order Do        used ← colours of v's already-coloured neighbours        colour[v] ← smallest colour number not in used    Return colour
  • One pass, each node checks its neighbours: \(O(V + E)\). Always gives a proper colouring.
  • Never needs more than \(\Delta + 1\) colours, where \(\Delta\) is the largest degree — each node has at most \(\Delta\) neighbours to avoid.
  • Whether it hits \(\chi(G)\) depends entirely on the order.
Welsh–Powell

A common ordering rule: colour nodes in order of decreasing degree, so the most constrained programs are placed first. On the gym it gives 3 blocks. Still a heuristic — no guarantee in general.

Same graph, worse order

Order: Yoga, Swim, Pilates, Spin, Climb, Boxing.

  1. 1 Yoga → 1. Swim has no coloured neighbours → 1.
  2. 2 Pilates touches Yoga (1) and Swim (1) → 2.
  3. 3 Spin touches Yoga (1), Pilates (2) → 3.
  4. 4 Climb touches Swim (1) → 2.
  5. 5 Boxing touches Spin (3), Swim (1), Climb (2) → 4.
  6. ✗ Four blocks — one more than needed.

Exact: backtracking for a \(k\)-colouring

Algorithm Colour(G, k, i):           // try to colour nodes i..n    If i > n Do        Return true                   // every node coloured    Foreach c from 1 To k Do        If no neighbour of node i has colour c Do            colour[i] ← c            If Colour(G, k, i + 1) Do                Return true            colour[i] ← none          // undo, try the next colour    Return false                       // dead end: backtrack
  • Worst case tries all \(k^n\) assignments: \(O(k^n)\) checks, each up to \(O(\Delta)\). Exponential.
  • Pruning — refusing a colour as soon as it clashes — cuts most branches in practice. To find \(\chi\), run it for \(k = 1, 2, 3, \dots\) until it succeeds.

Heuristic: simulated annealing for colouring

ComponentFor \(k\)-colouring
Representationa colour from 1..\(k\) for every node (clashes allowed)
Neighbourhoodchange the colour of one node — ideally one involved in a clash
Objectivenumber of edges whose ends share a colour — minimise to 0
Acceptalways if fewer clashes; sometimes if more, less often as it cools
Strength

Scales to thousands of nodes. Stopping early still leaves a timetable with only a few clashes, which may be acceptable.

Limitation

If it ends with clashes, you can't tell whether a \(k\)-colouring doesn't exist or the search just missed it. Backtracking can prove "impossible"; annealing can't.

Exam focus

Which one is not NP-hard?

Adapted from VCAA Algorithmics (HESS) Written Examination 2023, Section A Q20

Which one of the following problems is not in the NP-hard class? — three of these are this unit's additional topics

Afinding a solution to the 0-1 knapsack problem
Bfinding the minimum cost spanning tree of a graph
Cfinding a colouring of a graph with at most four colours
Dfinding the minimum cost solution to the travelling salesman problem
Why B

Prim's algorithm finds a minimum spanning tree in polynomial time, so MST is in P. Knapsack, 4-colouring (\(k \ge 3\)) and TSP are all NP-hard — unless P = NP.

Describe the problem and map onto it

Adapted from VCAA Algorithmics (HESS) Written Examination 2023, Section B Q10b–c

Question (1 + 2 marks)

(b) Describe the graph colouring problem. (c) Explain how allocating gym programs to timetable blocks without conflicts can be mapped to the graph colouring problem.

Answer

(b) Assign a colour to each node of a graph so that no two nodes joined by an edge have the same colour, using the minimum number of colours. [1]

(c) Each program is a node, with an edge between two programs if they conflict (a member is enrolled in both). Each timetable block is a colour. [1] A valid colouring places conflicting programs in different blocks, so it is a clash-free timetable, and a minimum colouring uses the fewest blocks. [1]

Where the marks are

Mapping marks need all three correspondences — node, edge, colour — and then the sentence linking a valid colouring to a valid timetable.

Classify it — and say why

Adapted from VCAA Algorithmics (HESS) Written Examination 2023, Section B Q10d

Question (2 marks)

The gym needs to find an allocation of programs to timetable blocks. State the complexity class of this problem and explain what features of the problem give rise to this classification.

Answer

Finding an allocation with the fewest blocks is graph colouring, which is NP-hard (asking whether \(k \ge 3\) blocks suffice is NP-complete). [1] A proposed allocation is easy to check — compare the blocks at each end of every conflict edge — but there is no known way to find one other than searching through the \(k^n\) possible assignments, which grows exponentially with the number of programs. [1]

Careful with 2 blocks

If the gym only had two blocks, the question "is there a clash-free timetable?" is 2-colouring — that is in P. Check \(k\) before you classify.

Check yourself

A graph is a single cycle of 7 nodes. What is its chromatic number?

3. Alternating two colours around an odd cycle forces the last node to clash with the first, so 2 fails; 3 is enough (alternate, then give the last node the third colour).

A verifier checks a proposed 3-colouring in \(2^n + n^4\) steps. Does that show 3-colouring is in NP?

No. NP needs a polynomial-time verifier, and \(2^n + n^4\) is exponential. (3-colouring is in NP — checking every edge is \(O(E)\) — but this verifier doesn't show it.) VCAA 2020 B Q12a

Why can greedy colouring never use more than \(\Delta + 1\) colours?

When a node is coloured it has at most \(\Delta\) neighbours, so at most \(\Delta\) colours are blocked. One of colours \(1..\Delta + 1\) must be free.

Backtracking or annealing for a school exam timetable with 400 exams? Justify briefly.

Annealing. Backtracking is \(O(k^n)\) with \(n = 400\) — infeasible in the worst case. Annealing scales and gives a usable timetable with few or no clashes, at the cost of no guarantee of the minimum number of sessions.

One sentence to remember

Graph colouring gives adjacent nodes different colours using as few as possible; 2 colours is easy, 3 or more is NP-complete, so real timetables use greedy orderings, backtracking for small cases, or annealing for big ones.
