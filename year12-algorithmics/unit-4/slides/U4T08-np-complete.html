NP-completeness and Reductions

Unit 4 AOS2 · Topic 8 of 17 — why thousands of hard problems are one hard problem

VCE Algorithmics (HESS) · Northcote High School

Reduction — solving A by using B

Definition

Problem \(A\) reduces to problem \(B\) if any instance of \(A\) can be transformed, in polynomial time, into an instance of \(B\) whose answer gives the answer to \(A\). Written \(A \le_p B\).

Everyday example

"Find the median of a list" reduces to "sort a list": sort it, then read the middle element. The transformation costs nothing extra, so any sorting algorithm gives you a median algorithm.

Read the direction carefully

\(A \le_p B\) means \(B\) is at least as hard as \(A\). If you can solve \(B\) quickly, you get \(A\) quickly for free. The arrow points from the easier problem to the harder one.

What a reduction proves — in both directions

Upper bound direction

\(A \le_p B\) and \(B\) is easy \(\Rightarrow\) \(A\) is easy.
Use it to inherit an algorithm.

Lower bound direction

\(A \le_p B\) and \(A\) is hard \(\Rightarrow\) \(B\) is hard.
Use it to prove hardness.

  • The second is the contrapositive of the first, and it is the one used to build the NP-complete class.
  • To show a new problem \(B\) is hard, you reduce a known hard problem to it — known hard \(\le_p\) new. Students routinely do this backwards.
Memory hook

"To prove my problem is hard, I show it could solve a problem everyone already agrees is hard."

NP-complete, defined

A problem \(X\) is NP-complete if

(1) \(X \in NP\) — a proposed solution can be checked in polynomial time; and
(2) \(X\) is NP-hard — every problem in NP reduces to \(X\) in polynomial time.

  • Condition 2 is extraordinary: it says \(X\) is universal for the whole class. Solve \(X\) quickly and you solve everything in NP quickly.
  • Which means: if any single NP-complete problem is in P, then P = NP.
  • Equally, if any single one is proved intractable, none of them is tractable.
They stand or fall together

Thousands of NP-complete problems, from timetabling to protein folding, are all the same problem wearing different clothes. That is the content of NP-completeness.

The distinction that gets tested

NP-hard is "at least as hard as" — it says nothing about membership. The Halting Problem is NP-hard and not in NP, because its solutions cannot be checked in polynomial time. Or at all.

Optimisation versions

"Find the shortest tour" is NP-hard but not NP-complete, because it is not a decision problem, so it cannot be in NP by definition.

Boolean satisfiability — the problem at the root

Careful — the acronym clashes

In this topic SAT means Boolean satisfiability, a problem in logic. It has nothing to do with your School-Assessed Task. To keep them apart, these slides say satisfiability for the problem and spell out School-Assessed Task in full.

The ingredients

Variable: a symbol that is either true or false — \(x\), \(y\), \(z\).
Literal: a variable or its negation — \(x\) or \(\lnot x\).
Clause: literals joined by OR — \((x \lor \lnot y \lor z)\).
Formula: clauses joined by AND — this shape is called conjunctive normal form.

The decision problem

Satisfiability (SAT): given a Boolean formula, is there an assignment of true/false to its variables that makes the whole formula true? Yes or no.

Worked example — satisfiable or not?

Formula 1

\[(x \lor y) \land (\lnot x \lor z) \land (\lnot y \lor \lnot z)\]

  1. 1 Try \(x = \text{T}\). Clause 2 then needs \(z = \text{T}\).
  2. 2 With \(z = \text{T}\), clause 3 needs \(\lnot y\), so \(y = \text{F}\).
  3. 3 Check clause 1: \((\text{T} \lor \text{F}) = \text{T}\). All three hold.
  4. ✓ Satisfiable, e.g. \(x{=}\text{T}, y{=}\text{F}, z{=}\text{T}\).
Formula 2

\[(x \lor y) \land (x \lor \lnot y) \land (\lnot x \lor y) \land (\lnot x \lor \lnot y)\]

  1. 1 Only two variables, so four assignments — check them all.
  2. 2 \(x{=}\text{T},y{=}\text{T}\) fails clause 4. \(x{=}\text{T},y{=}\text{F}\) fails clause 3.
  3. 3 \(x{=}\text{F},y{=}\text{T}\) fails clause 2. \(x{=}\text{F},y{=}\text{F}\) fails clause 1.
  4. ✓ Unsatisfiable — no assignment works.
Notice the asymmetry

To show a formula is satisfiable you exhibit one assignment, and anyone can check it in polynomial time — which is exactly why satisfiability is in NP. To show it is not, you must rule out all \(2^n\) assignments. Solving and checking are not the same job.

Why satisfiability is the root of everything

  1. 1 It is in NP. Given a proposed assignment, substitute and evaluate each clause — linear in the size of the formula.
  2. 2 It is NP-hard. Cook and Levin showed that the entire computation of any nondeterministic polynomial-time machine can be encoded as a Boolean formula that is satisfiable exactly when the machine accepts.
  3. 3 So every problem in NP reduces to it — not by a clever problem-specific trick, but by a uniform construction from the definition of the class.
  4. ✓ That makes satisfiability the seed: the first problem shown NP-complete without relying on any earlier one.
A nuance worth knowing

2-satisfiability — every clause limited to two literals — is in P. 3-satisfiability is NP-complete. One literal per clause is the difference between easy and hard, which shows how sharp the boundary can be.

Where the first one came from

  1. 1 Cook and Levin, 1971. Proved that Boolean satisfiability is NP-complete, directly from the definition of nondeterministic computation — the first such proof, and the only one that could not lean on an earlier result.
  2. 2 Karp, 1972. Reduced satisfiability to 21 other problems, showing each was NP-complete too — including graph colouring, knapsack and Hamiltonian circuit.
  3. 3 Today. Thousands are known. Each new proof is one reduction from a problem already on the list.
  4. ✓ Only the first proof was hard. Every subsequent one stands on it.
Why this matters for your answers

Asked to show a problem is NP-complete, the expected structure is: (1) show it is in NP by describing the polynomial-time check; (2) name a known NP-complete problem and reduce it to yours.

Worked example — a reduction you can write down

Claim

Hamiltonian Circuit \(\le_p\) TSP-decision. (HC: does this graph contain a cycle visiting every node exactly once?)

  1. 1 Transform the input. Given a graph \(G\) with \(n\) nodes, build a complete weighted graph on the same nodes: weight 1 if the edge exists in \(G\), weight 2 if it does not.
  2. 2 Set the threshold. Ask TSP-decision: is there a tour of total length \(\le n\)?
  3. 3 Argue both ways. A tour of length \(\le n\) must use \(n\) edges each of weight 1, i.e. all real edges of \(G\) — a Hamiltonian circuit. Conversely a Hamiltonian circuit gives a tour of exactly \(n\).
  4. 4 Check the cost. Building the new graph takes \(O(n^2)\) — polynomial. Reduction complete.
  5. ✓ So TSP-decision is at least as hard as Hamiltonian Circuit, which is known NP-complete.

The anatomy of any reduction answer

  • The map. How do you turn an instance of the known problem into an instance of yours?
  • The equivalence. Yes-instances map to yes-instances, and no-instances to no-instances. Both directions, explicitly.
  • The cost. The transformation must be polynomial — otherwise nothing is inherited.
Where marks are lost

Describing the map and stopping. Without the equivalence argument, you have shown a transformation exists, not that it preserves the answer — which is the entire point.

Nothing exotic is expected

At VCE level you are asked to explain what a reduction establishes far more often than to construct one. Know the logic cold; the constructions are a bonus.

Exam focus

Which problem is not NP-hard?

Adapted from VCAA Algorithmics (HESS) Written Examination 2023, Section A Q20

Three of these are NP-hard — which one is not?

Athe travelling salesman problem
Bgraph colouring
Cfinding a minimum spanning tree
Dthe 0/1 knapsack problem
The discriminator

Three of these have no known polynomial algorithm. One you learned to solve efficiently in Unit 3. Which, and with what algorithm?

Working it through

  1. 1 C is solvable in polynomial time — Prim's or Kruskal's finds a minimum spanning tree in \(O(|E|\log|V|)\). So MST is in P.
  2. 2 Could a problem in P still be NP-hard? Only if P = NP. Since that is not established, a P problem is not considered NP-hard.
  3. 3 Check the others: TSP, graph colouring and 0/1 knapsack are all classic NP-hard problems with no known polynomial algorithm.
  4. ✓ Answer: C.
The trap in D

0/1 knapsack has a dynamic programming solution running in \(O(nW)\), which looks polynomial. It is not: \(W\) is a value, and writing it down takes only \(\log W\) bits, so \(O(nW)\) is exponential in the input size. This is called pseudo-polynomial, and Topic 9 returns to it.

Elaboration — the pseudo-polynomial trap

The knapsack case is worth unpacking, because it is the neatest example of why input size must be measured in bits.

Number of items \(n\)Capacity \(W\)
How it is written down\(n\) entriesabout \(\log_2 W\) bits
So input size is\(\Theta(n)\)\(\Theta(\log W)\)
DP table cost \(O(nW)\) becomes\(O(n \cdot 2^{\log_2 W})\) — exponential in the size of \(W\)
Concretely

Add one digit to the capacity and the input grows by a few bits — but the table gets ten times bigger. That is exponential behaviour, disguised.

Rule

Complexity is always measured against the number of bits needed to write the input down, never against the numeric value of a parameter.

Check yourself

State the two conditions for a problem to be NP-complete.

(1) It is in NP — a proposed solution can be verified in polynomial time. (2) It is NP-hard — every problem in NP reduces to it in polynomial time. Condition 2 alone gives NP-hard; both together give NP-complete.

What would follow from a polynomial-time algorithm for graph colouring?

Graph colouring is NP-complete, so every problem in NP reduces to it in polynomial time. A fast colouring algorithm would therefore solve every NP problem in polynomial time, proving P = NP — and breaking most modern cryptography as a side effect.

Why is the Halting Problem NP-hard but not NP-complete?

It is NP-hard because every NP problem reduces to it. It is not NP-complete because it is not in NP — there is no polynomial-time check for a claimed answer, since the problem is undecidable and no algorithm decides it at all.

Define Boolean satisfiability, and explain why it is in NP.

Given a Boolean formula built from variables joined by AND, OR and NOT, is there an assignment of true/false to the variables making the whole formula true? It is in NP because a proposed assignment can be verified in polynomial time — substitute the values and evaluate each clause. (Not to be confused with the School-Assessed Task.)

To prove a new problem \(X\) is NP-hard, which way does the reduction go?

Known NP-complete problem \(\le_p X\) — reduce the known-hard problem to \(X\). This shows \(X\) is at least as hard. Doing it the other way (\(X \le_p\) known) only shows \(X\) is no harder, which proves nothing about hardness.
