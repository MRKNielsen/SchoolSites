Recurrences and the Master Theorem

Unit 4 AOS1 · Topic 6 of 6 — solving the equation, and knowing when you can't

VCE Algorithmics (HESS) · Northcote High School

Two methods, and a rule for choosing

Topic 5 produced equations. This topic turns them into bounds.

  • Expansion (telescoping) — substitute the recurrence into itself repeatedly, spot the pattern, sum it. Always works; slower.
  • The Master Theorem — a lookup table for one specific family. Instant when it applies; useless when it doesn't.
The choosing rule

The Master Theorem applies to divide-and-conquer recurrences: \(T(n) = a\,T(n/b) + \ldots\), where the size is divided. If your recurrence subtracts — \(T(n-1)\), \(T(n-2)\) — you must expand.

Solving by expansion

Solve \(T(n) = T(n-1) + c\), with \(T(1) = c\)
  1. 1 Substitute once: \(T(n) = [T(n-2) + c] + c = T(n-2) + 2c\).
  2. 2 Again: \(T(n) = T(n-3) + 3c\).
  3. 3 Spot the pattern after \(k\) steps: \(T(n) = T(n-k) + kc\).
  4. 4 Stop at the base case: set \(n - k = 1\), so \(k = n-1\).
  5. 5 Substitute back: \(T(n) = T(1) + (n-1)c = c + (n-1)c = nc\).
  6. ✓ \(T(n) = \Theta(n)\).
The five moves, every time

Substitute · substitute again · generalise to \(k\) · choose \(k\) to reach the base case · substitute back. Write them as five lines and the marks follow.

Worked example — when each level costs \(O(n)\)

Solve \(T(n) = T(n-2) + n\)

This is the one the Master Theorem cannot touch — the size is reduced by subtraction.

  1. 1 Expand: \(T(n) = T(n-4) + (n-2) + n\), then \(T(n) = T(n-6) + (n-4) + (n-2) + n\).
  2. 2 Pattern: the added terms are \(n, n-2, n-4, \ldots\) — an arithmetic sequence stepping down by 2.
  3. 3 How many terms? We reach the base case after about \(n/2\) steps.
  4. 4 Sum them: \(n + (n-2) + \cdots \approx \dfrac{n}{2} \times \dfrac{n}{2}\) on average — roughly \(\dfrac{n^2}{4}\).
  5. ✓ \(T(n) = \Theta(n^2)\).
Shortcut worth knowing

\(T(n) = T(n-k) + O(n)\) is always \(O(n^2)\): about \(n/k\) levels, each costing up to \(n\). The constant \(k\) only affects the hidden factor.

The Master Theorem

The form (as given on the exam formula sheet)

\[ T(n) = \begin{cases} a\,T\!\left(\dfrac{n}{b}\right) + k n^c & n > 1 \\[6pt] d & n \le 1 \end{cases} \] with \(a > 0\), \(b > 1\), \(c \ge 0\), \(d \ge 0\), \(k > 0\).

The solution — compare \(\log_b a\) against \(c\)

\[ T(n) = \begin{cases} O(n^c) & \text{if } \log_b a < c \\[3pt] O(n^c \log n) & \text{if } \log_b a = c \\[3pt] O(n^{\log_b a}) & \text{if } \log_b a > c \end{cases} \]

The sheet is supplied in the exam — you do not need to memorise it. You do need to identify \(a\), \(b\) and \(c\) correctly and compare in the right direction.

What the three cases actually say

\(\log_b a\) measures how fast the number of subproblems grows. \(c\) measures how expensive the work at each level is. The theorem asks which one wins.

CaseWho dominatesWhere the cost lives
\(\log_b a < c\)the combining workthe top level — the root's \(n^c\) swamps everything below
\(\log_b a = c\)a tiespread evenly across all \(\log n\) levels — hence the extra \(\log n\)
\(\log_b a > c\)the recursionthe leaves — there are so many base cases they dominate
Merge sort is the tie

\(2T(n/2) + O(n)\): \(a = 2\), \(b = 2\), \(c = 1\), so \(\log_2 2 = 1 = c\). Every level costs \(n\), there are \(\log n\) levels — exactly the picture from Topic 5.

Worked examples — one of each case

  1. 1 \(T(n) = 2T(n/2) + n\). \(a=2, b=2, c=1\). \(\log_2 2 = 1 = c\) → tie → \(O(n\log n)\). (Merge sort.)
  2. 2 \(T(n) = 4T(n/2) + n\). \(a=4, b=2, c=1\). \(\log_2 4 = 2 > 1\) → leaves win → \(O(n^{2})\).
  3. 3 \(T(n) = 2T(n/2) + n^2\). \(a=2, b=2, c=2\). \(\log_2 2 = 1 < 2\) → root wins → \(O(n^{2})\).
  4. 4 \(T(n) = T(n/2) + 1\). \(a=1, b=2, c=0\). \(\log_2 1 = 0 = c\) → tie → \(O(\log n)\). (Binary search.)
Watch \(c = 0\)

Constant work outside the recursion means \(kn^0 = k\), so \(c = 0\). Students often write \(c = 1\) here and get \(O(n)\) instead of \(O(\log n)\).

Exam focus

Apply the theorem

Adapted from VCAA Algorithmics (HESS) Written Examination 2023, Section A Q13

Question

The recurrence \(T(n)\) gives the running time of an algorithm with respect to its input size \(n\):

\[ T(n) = \begin{cases} 8\,T\!\left(\dfrac{n}{2}\right) + 5n^{2} & n > 1 \\[4pt] 300 & n \le 1 \end{cases} \]

What is the Big-O time complexity? — compare \(\log_b a\) with \(c\)

A\(O(n^{2})\)
B\(O(n^{2}\log n)\)
C\(O(n^{3})\)
D\(O(n^{2}\log_2 8)\)

Working it through

  1. 1 Read off the parameters. \(a = 8\) (eight subproblems), \(b = 2\) (size halved), and \(kn^c = 5n^2\) so \(c = 2\). The \(k = 5\) and \(d = 300\) do not affect the answer.
  2. 2 Compute \(\log_b a\): \(\log_2 8 = 3\).
  3. 3 Compare: \(3 > 2\), so \(\log_b a > c\) — the third case, dominated by the leaves.
  4. 4 Apply: \(T(n) = O(n^{\log_b a}) = O(n^{3})\).
  5. ✓ Answer: C.
The distractors

A is what you get by reading \(c\) and stopping. B is the tie case — chosen by anyone who assumes every divide-and-conquer is \(n\log n\). D is a nonsense expression built from the right symbols, which catches pattern-matchers.

The extended-response version

Adapted from VCAA Algorithmics (HESS) Written Examination 2023, Section B Q7b(ii) and Q7c(ii)

b(ii) — 2 marks

Solve \(S(n) = 3S(n/3) + O(n)\), giving your answer in Big-O notation.

Response

\(a = 3\), \(b = 3\), \(c = 1\). Then \(\log_3 3 = 1 = c\), so the tie case applies and \(S(n) = O(n\log n)\).

c(ii) — 2 marks

Deduce the worst-case complexity when \(T(n) = T(n-2) + O(n)\), and state it in Big-O notation.

Response

The Master Theorem does not apply — the size is reduced by subtraction, not division. Expanding: the recursion has about \(n/2\) levels and each level does \(O(n)\) work, so the total is \(O(n^2)\).

Elaboration — the same machine, two orders of magnitude apart

Those two parts describe one ball-sorting machine. The only difference is how evenly it splits.

Even three-way splitEverything in one bag
Recurrence\(3S(n/3) + O(n)\)\(T(n-2) + O(n)\)
Depth\(\log_3 n\)\(n/2\)
Solution\(O(n\log n)\)\(O(n^2)\)
\(n = 10^6\)≈ 20 million steps≈ \(10^{12}\) steps
This is quicksort's story too

Balanced partitions give \(\Theta(n\log n)\); maximally unbalanced ones give \(\Theta(n^2)\). Same algorithm, different input — which is why Topic 2 insisted you name the case.

Your decision procedure

  1. 1 Is the size divided or subtracted? Divided → Master Theorem. Subtracted → expand.
  2. 2 If dividing: read \(a\), \(b\), \(c\). Compute \(\log_b a\). Compare with \(c\). Apply the matching case.
  3. 3 If subtracting: expand twice, generalise to \(k\), set \(n - k\) to the base case, sum the added terms.
  4. 4 Sanity check against the shape table from Topic 5. Disagreement means arithmetic, not method.
State when the theorem doesn't apply

If a question gives you \(T(n-k)\), saying "the Master Theorem does not apply here because the input is reduced by subtraction rather than division" is itself worth a mark. Do not silently misuse it.

Check yourself

Solve \(T(n) = 9T(n/3) + n^2\).

\(O(n^2\log n)\). \(a=9\), \(b=3\), \(c=2\); \(\log_3 9 = 2 = c\), the tie case. A nice illustration that the tie doesn't only happen at \(n\log n\).

Solve \(T(n) = 3T(n/4) + n\).

\(O(n)\). \(a=3\), \(b=4\), \(c=1\); \(\log_4 3 \approx 0.79 < 1\), so the root dominates and the answer is \(O(n^c) = O(n)\). The recursion is cheap enough to disappear into the top-level work.

Why can't the Master Theorem solve \(T(n) = 2T(n-1) + 1\)?

It requires the form \(a\,T(n/b)\) — the input divided by a constant. Here it is reduced by subtraction, so no valid \(b\) exists. Expanding gives depth \(n\) with the work doubling each level: \(\Theta(2^n)\). (This is Towers of Hanoi.)

An algorithm splits into 2 halves and does \(O(1)\) combining. Solve it.

\(O(n)\). \(T(n) = 2T(n/2) + O(1)\): \(a=2\), \(b=2\), \(c=0\); \(\log_2 2 = 1 > 0\), so the leaves dominate and \(T(n) = O(n^{\log_2 2}) = O(n)\). There are \(n\) leaves, and they are the whole cost.
