The reason to use one

Some tasks resist specification. Nobody can write the rules that distinguish a cat from a dog in pixels — but we can supply thousands of labelled examples and let the parameters be fitted.

How a data-driven algorithm learns

  1. 1 Setup. Collect labelled examples — inputs with known correct outputs.
  2. 2 Model. Choose a structure with adjustable parameters (in a network, the weights and biases).
  3. 3 Measure. Run the model on the training data and compute its error.
  4. 4 Adjust. Change the parameters slightly in the direction that reduces the error.
  5. 5 Repeat until the error stops improving.
  6. ✓ Training is optimisation over parameters — the AOS2 search landscape again, now with millions of dimensions.
Connect it back

Local optima, and getting stuck in them, are exactly the Topic 10–11 problem. The vocabulary changes; the geometry does not.

Support vector machines — the widest street

  • Binary classification by a line in 2-D, or a hyperplane in higher dimensions.
  • Many lines separate the training data. The SVM's objective is to choose the one that maximises the margin — the distance to the nearest point of each class.
  • Those nearest points are the support vectors; they alone determine the boundary. Moving any other point changes nothing.
  • A wide margin means new points near the training data still land on the correct side — better generalisation.

Not separable? Add a dimension

  1. 1 The problem. Points inside a circle versus outside cannot be split by any straight line in 2-D.
  2. 2 The trick. Invent a new feature: \(z = x^2 + y^2\), the squared distance from the origin.
  3. 3 In \((x,y,z)\)-space, the inside points now sit low and the outside points high — a flat plane separates them perfectly.
  4. 4 Generalise. Map data into a higher-dimensional space where a linear boundary works, then classify linearly there.
  5. ✓ The boundary is linear in the new space, and curved when projected back to the original.
Try it

XOR data — \((0,0)\) and \((1,1)\) in class A; \((0,1)\) and \((1,0)\) in class B — is not linearly separable. Find a third feature that separates it. (Hint: consider \(x \times y\).)

The multilayer perceptron

  • Neuron: takes a weighted sum of its inputs, adds a bias, and passes the result through an activation function.
  • Layers: input (the features) → one or more hidden layers → output (the classification).
  • Every connection carries a weight. These are the parameters training adjusts.
  • Hidden layers construct intermediate features automatically — the learned version of the "add a dimension" trick.

Forward propagation — evaluating a network

Worked example

Inputs \(x_1 = 1\), \(x_2 = 0\). Hidden neuron \(h\): weights \(0.5\) and \(-0.3\), bias \(0.1\), step activation (fires if the sum is \(> 0\)).

  1. 1 Weighted sum at \(h\): \(0.5(1) + (-0.3)(0) + 0.1 = 0.6\).
  2. 2 Activation: \(0.6 > 0\), so \(h\) outputs 1.
  3. 3 Output neuron: weight from \(h\) is \(0.8\), bias \(-0.5\), so \(0.8(1) - 0.5 = 0.3\).
  4. ✓ \(0.3 > 0\), so the network classifies 1.
Show the sums

That is the whole procedure: weighted sum, add bias, apply activation, layer by layer, left to right. Marks are for the arithmetic shown, not the final label.

The consequence

A model is only as good as its performance on data it has never seen. Training accuracy alone is marketing — which is exactly what the exam question on the next slides is about.

Exam focus

Find the weight

Adapted from VCAA Algorithmics (HESS) Written Examination 2023, Section A Q15

Setup

A small network has three input nodes \(i_0, i_1, i_2\) feeding a single output node \(a_0\). The connection from \(i_0\) has unknown weight \(X\); from \(i_1\) the weight is \(1\); from \(i_2\) it is \(-2\).

The inputs are set to \(i_0 = 0.5\), \(i_1 = 0.5\), \(i_2 = 1\).

What value of \(X\) makes the activation of \(a_0\) equal to 0? — set up the weighted sum

A\(-2\)
B\(0\)
C\(1\)
D\(3\)

Working it through

  1. 1 Write the weighted sum at \(a_0\): each input times its weight, added together. \[ 0.5 \times X \;+\; 0.5 \times 1 \;+\; 1 \times (-2) \]
  2. 2 Simplify: \(0.5X + 0.5 - 2 = 0.5X - 1.5\).
  3. 3 Set the activation to zero: \(0.5X - 1.5 = 0\).
  4. 4 Solve: \(0.5X = 1.5\), so \(X = 3\).
  5. ✓ Answer: D.
Where errors creep in

Forgetting that \(i_0\) is \(0.5\), not \(1\) — giving \(X = 1.5\), which is not offered, so the mistake is invisible until you notice no option matches. If your answer isn't on the list, recheck the multiplications first.

What is wrong with this training approach?

Adapted from VCAA Algorithmics (HESS) Written Examination 2021, Section B Q10

Question (4 marks)

A student builds a neural network to classify photographs as showing him or not showing him.

a. Describe a motivation for using a neural network rather than a traditional algorithm. (2 marks)

b. He trains it on a set of 100 photographs containing both. He then tests accuracy by renaming those same photographs "Photo 1", "Photo 2" and so on, and running the model on the renamed files. Describe two problems with this approach. (2 marks)

Working it through

a — motivation

There is no practical way to write explicit rules that identify a face from pixel values — the variation in lighting, angle and expression is far too great to specify by hand. A neural network instead learns the distinguishing features from labelled examples, so the developer supplies data rather than rules.

  1. 1 Problem one — testing on the training set. Renaming the files changes nothing about their content; the model is being evaluated on the very photographs it learned from. It may simply have memorised them, so the accuracy figure says nothing about performance on new photographs. A separate held-out test set is required.
  2. 2 Problem two — the dataset is far too small and probably unrepresentative. 100 photographs cannot cover the range of lighting, angles, backgrounds and ages the model will meet, so it will overfit to incidental features of those particular images.
  3. ✓ Both problems point the same way: the reported accuracy will be far higher than real-world performance.

Elaboration — why the renaming is a red herring

The renaming detail is deliberately placed. It invites you to think something has been anonymised and therefore made fair.

  • The network never sees filenames. It sees pixels — which are identical before and after renaming.
  • What matters for a valid test is not whether the tester knows which photo is which, but whether the model has seen that image during training.
  • The correct procedure: split the data before training into a training set and a test set, train only on the first, and evaluate only on the second.
The general principle

Never evaluate on data the model was trained on. Any accuracy figure produced that way measures memorisation, not learning.

Check yourself

State the SVM's optimisation objective and why it aids generalisation.

Among all hyperplanes separating the training data, choose the one maximising the margin — the distance to the nearest point of each class. A wide margin means a new point near the training data still falls on the correct side, so small variations do not flip the classification.

A model scores 99% on training data and 62% on new data. Diagnose and fix.

Overfitting — it has memorised the training set including its noise. Fixes: gather more and more varied training data, reduce model capacity, or use held-out validation to stop training before memorisation sets in.

Compute: inputs 1 and 2, weights 0.4 and −0.1, bias 0.3, step activation.

Weighted sum \(= 0.4(1) + (-0.1)(2) + 0.3 = 0.4 - 0.2 + 0.3 = 0.5\). Since \(0.5 > 0\), the neuron fires, outputting 1. Always show the sum — that is where the marks are.

Why use a neural network rather than a designed algorithm for face recognition?

The task cannot be specified as explicit rules — no one can write conditions on pixel values that capture a face across lighting, pose and expression. A network learns the discriminating features from labelled examples, shifting the developer's job from writing rules to curating data.
